# README.md（AI引き継ぎ用）— Printify 日本文化×漢字Tシャツ量産プロジェクト

## 1. プロジェクト概要（何を作っているか）
Printify を使い、**外国人向けの「日本文化」モチーフTシャツ**を販売している。  
コンセプトは **“静けさ／余白／筆致（ink）／日本美学”**。  
デザインは基本的に **絵（背景アート）＋短い漢字（1〜2文字 or 2〜3文字熟語）** で構成し、海外の「Japan aesthetic / zen / ink / minimal」需要を狙う。

- 販売チャネル：Printifyの公開ストア（例：`https://yukiandink.printify.me/`）
- 主力スタイル：水墨画調、筆円（円相）、夜景、霧、雨、波など
- 重要な運用方針：**漢字はユーザーが後から当てはめる（文字化け・AI生成感対策）**  
  → AIは「背景画像のみ（文字なし）」を出力する。

## 3. 主要な定義・仕様（ブランドコンセプト／ターゲット／プロンプト型）

### ブランドコンセプト（世界観）
- 静けさ、余白、無音、霧、月、雨、海の気配
- 和の象徴（富士、鳥居、波、鯉、桜、食）を**説明しやすい形でミニマル化**
- 「動」より「静」。派手さより“奥行き”や“余韻”を重視

### ターゲット
- 海外（主に英語圏）の「Japan aesthetic / zen / minimal / ink art」好き
- “日本語（漢字）が入ったデザイン”に惹かれる層
- ギフト需要も意識（説明文は情景・意味が伝わるように）

### 制作フロー（黄金ルート）
今後は必ずこの順で進める：

1) **① 構図＆漢字候補（＋フォント種類候補）すり合わせ**  
2) **② 画像出力（背景のみ・文字なし）**  
3) **③ 製品名・説明文（英文＆和訳）＋次案選定**

### プロンプトの型（要点）
- 出力するのは**背景画像のみ（文字なし）**
- 水墨画／墨のにじみ／和紙粒子（控えめ）
- 余白を確保（漢字の挿入予定位置：右下／右側などを設計段階で決める）
- 黒T前提の場合：
  - 背景を“完全な黒”にしすぎず、薄霧グレー等で輪郭が沈まないようにする
  - 白〜薄墨の線でコントラストを確保
- 差別化ルール：
  - 鳥居シリーズは「霧・森・参道・門」
  - 波シリーズは「海のみ」「うねり」「泡」「水平線」「円相」などで表情を変える  
  - 同じ“霧・濃淡”に寄りすぎると鳥居と似てしまうので注意

### 漢字（文字は後入れ）
- 漢字はユーザーが後から当てはめるため、AIは候補提示のみ
- 1〜2文字（または短い熟語）を推奨し、シリーズで文字数・位置を揃える
- フォント候補（ユーザー側で適用）：
  - 明朝（上品・アート）
  - 行書（流れ・情緒）
  - 楷書（読みやすい）
  - 隷書（古典的で海外受け良い）

## 4. 決定事項と未解決事項（重要ルール／保留課題）

### 決定事項（重要ルール）
- **画像は背景のみ出力（文字なし）**：漢字はユーザーが別途合成する
- 進行は「①→②→③」の黄金ルートに固定
- 既存作品を見て「似すぎる」場合は、構図・背景要素・主役を切り替えて差別化する
  - 例：鳥居シリーズ（参道＋霧）と似た雨作品になったため、
    - “森・霧”要素を捨てて “海だけ” にして波シリーズを差別化
- シリーズ化で棚を作る（単発追加は避ける）
  - 目標：ストア全体として12点程度の“店感”を作る

### 未解決事項（保留）
- 波シリーズの次の2作目/3作目の確定（現状候補：**凪** or **渦**）
- 既存の「鯉・ラーメン・桜花びら・波」単発商品の“柱化”手順
- Tシャツ以外（マグ／トート／帽子）への展開タイミング
  - 方針は「上位2デザインだけ横展開」、帽子はアイコン化が必要で後回し

## 5. AIへの要望（新しいAIが守るべきトーン＆注意点）

### トーン
- 落ち着きと礼節、配慮と温かさ（過剰に形式的にならない）
- 質問で会話を引っ張りすぎず、**まず案を提示して前に進める**
- ただし設計条件が成果に直結する場合（例：黒T前提、余白位置、差別化意図など）は最小限の確認を入れてよい

### 注意点（特に重要）
- **絶対に文字入り画像を生成しない**（ユーザーが後で漢字を当てる）
- **Tシャツ合成画像は不要**（ユーザー側で当て込みする）
- 「似すぎ問題」が起きたら、以下の順に差別化を提案する：
  1) 主役の変更（波→うねり／波紋→海面など）
  2) 背景要素の削除（森・霧・参道を捨てる等）
  3) 構図の型を変える（円相あり/なし、視点、切り取り）
  4) コントラスト設計（黒Tで沈まない明度設計）

### 次に新AIがやるべき具体タスク（最短復帰手順）
1) 波シリーズの次案を①で提案：
   - 「凪（水平線＋余白）」または「渦（回転の流れ）」の構図＆漢字＆フォント候補
2) ユーザーが選んだら②：背景画像のみ出力（文字なし）
3) ③：製品名・英文説明＋和訳＋次案選定（シリーズを3点セットで締める）
4)　Etsyストアとの連携
5) ジグソーパズルもセクションを分けて販売開始（テーマは同じく日本文化）
