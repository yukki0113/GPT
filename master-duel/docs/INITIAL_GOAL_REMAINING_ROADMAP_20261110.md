# Master Duel: 初期ユースケースまでの残工程と受入順序（2026-11-10）

正本: [BASIC_DESIGN.md](BASIC_DESIGN.md)。本書は2026-11-10時点の**実装到達点と未実装境界**を区別する。初期要求は「SR以下の低コストテーマを発掘し、所持UR等を再利用して**新規UR生成0枚**のデッキを比較・提案すること」。単なるカード一覧ではない。対象は個人非公開のMaster Duelのみ。ゲームアカウントへの自動アクセス・公開カードデータ配布は対象外。

## 現在地

- 完了：本番SQLite世代1にMD候補13,948件の基本カード、日本語効果文13,948件。KONAMI ID一意、入力元JSONのハッシュ固定。所持情報は0件（つまり**全件UNKNOWN**であって0枚所持ではない）。P1/P2/P3基本操作が確認済み。効果内容・レアリティは未独立検証の出典を明記。
- 今回追加：`deck_assistant/search.py` が本番DBへの**読み取り専用**で名称/種類/属性/レア・日本語効果語句AND検索と原文根拠を取得。`deck_assistant/cost.py` が**与えられたレシピ**に対して`STRICT_NO_UR`・`LOW_RARITY_CORE`・`OWNED_UR_ONLY`・`UR_BUDGET`・`CP_BUDGET`の条件と所持不足を保守的に評価する。独立した意味理解、テーマ抽出、最適デッキ生成ではない。
- 検証範囲：数値とUNKNOWNが絡む判定は`PASS`/`FAIL`/`INDETERMINATE`を分離。規制未登録・所持不明を合法/無料扱いしない。CP単価は**呼び出し側が入力した仮定値**であり、現行公式価格を保証しない。

## 必須残工程（順序）

| 段 | 目的 | 具体的実装 | 最低受入条件 |
|---|---|---|---|
| M1 | 効果・基本属性検索 | SQLiteから名称・種類・属性・レア・効果本文を絞り込み。P2初期語句検索。 | 実13,948件DBの読み込み、照合、原文・出典・時点返却、書込ゼロ、引用語句検索の再現性。**今回の実装対象**。 |
| M2 | 所持枚数の実入力と優先リスト | 汎用カードを初期優先、全カード入力可。音声/CSV/JSON→P3プレビュー→人の確認→単一ライターで新ZIP保存/独立読戻し→HEAD切替。誤認カードと同名カードは保留。 | UNKNOWN/0/1以上の区別、バッチ訂正・履歴・取消、既存DBの保全、実カード複数件のDrive書込往復。初期入力は「灰流うらら」「増殖するG」「墓穴の指名者」「無限泡影」等を優先候補とし、所持枚数は**一切仮定しない**。 |
| M3 | 施行日付きMD禁止制限 | `current.vector.json`のような候補値をsnapshotに格納し、最新ゲーム内/信頼できる別情報との照合・format/effective_fromを保持。 | 0/1/2/3、未掲載UNKNOWN、古い/未検証候補と確定値を区別。制限不明ならレシピ合法性を確定しない。 |
| M4 | 効果の意味・テーマ関連検索 | 日本語原文からドロー/サーチ/手札交換/蘇生/特殊召喚/妨害、発動条件、コスト、ターン制限、対象条件、ロックの候補ファセットを抽出。カードとテーマの直接・間接関係を保持。 | 「ドロー」と「手札に加える」を区別。候補タグに原文抜粋・根拠位置・confidence、最終確認ステータス。単純な語句一致を意味理解と呼ばない。 |
| M5 | 汎用札・出張パッケージ | 単体汎用と複数枚エンジンを別モデルで管理。デモンスミス／スピードロイド／壊獣を初期検証候補。必要メイン/EX枠、初動・中継・終着点、必須/代替、競合ロックを登録。 | 同一カードがテーマ/汎用/エンジンに重複所属可。セット採用枚数・EX枠・制約を検証し、事実と仮説を区別。 |
| M6 | 低レアテーマ発掘・レシピ生成 | 検証済みのテーマ最小成立セットを構成し、候補レシピを生成。M2所持/M3規制/M4効果/M5エンジンを接続。 | **既定`LOW_RARITY_CORE`**: テーマ中核の必須UR0、汎用/出張URは所持済みのみ、新規UR0。**`STRICT_NO_UR`**: メイン/EXともUR0。未登録URを所持扱いしない。MAIN40–60/EX0–15、規制、コストをチェック。少なくとも複数テーマを候補比較し、採用・不採用理由を付す。 |
| M7 | CPとパック逆引き | 現行CP/生成可否を出典付きで登録。必要カード→ピックアップパック→解放のために生成候補と必要枚数を逆引き。販売中/未解放/終了を分離。 | パックの現在販売と過去収録を混同せず、候補解放キーを「確実に解放できる」と断定しない。未確認の確率・ジェム節約額を捏造しない。 |

## 段階的に使える状態

- **M1時点**：カードと原文の条件検索。汎用/出張の自動判定や強さ推奨はまだできない。
- **M2+M3時点**：所持枚数と規制を踏まえた**入力済みレシピ**の不足計算。規制が未検証なら確定とせず候補として表示。
- **M4+M5+M6時点**：最初の完成目標「低レアテーマ＋所持UR活用・新規UR0のデッキ候補比較」。強さの完全保証やゲーム裁定の完全再現は対象外。
- **M7+M8時点**：最初の全UC（UC-01〜07）とパック解放ナビを通して使える状態。

## 実装・運用上の不変条件

1. 一切の実カード本文・所持枚数を公開Git/CIログに含めない。公開側にはコード・架空fixture・件数/ハッシュ監査だけ置く。
2. SQLiteスナップショットは正本Drive内の不変ZIP、HEADは単一ライターで更新。CASが無いため同時ライターを禁止し、バックアップ＋独立読戻しが終わるまで切り替えない。
3. MD固有のレアリティ・規制はOCGと別扱い。入力データの版を持ち、未照合ソースを`GAME_VERIFIED`に偽装しない。
4. カード効果の引用だけで展開・合法性を断定しない。`LOW_RARITY_CORE` の「テーマ中核」は効果の原文・EX必須札・採用制約に基づき人間が監査する。
5. 更新後、正式なP1/P2/P3の既存回帰に加え、各Mの新規架空fixtureテストと、非公開本番ZIPの読み取り専用スモークを実施する。
