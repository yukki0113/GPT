# M6-7 固定的役割重複減点の撤廃（2026-11-16）

## 決定した方針

同じ役割・汎用グループに既に何枚あるかだけではカードの採用価値を下げない。たとえば灰流うらら3、ドロール＆ロックバード2、エフェクト・ヴェーラー3、無限泡影3の11枚構成を「妨害が多い」という理由で減点しない。テーマの初動・展開が成立し、残り枠に収まるなら十分に採用候補となる。

参考：Game8のデッキ構築解説 <https://game8.jp/yugioh-masterduel/426127> はテーマギミック・カードごとの採用枚数・対戦後調整を優先する。記事自身がM6-7の特定の採点式を推奨するわけではないため、数式の修正はこのプロジェクトの独立した設計判断。

## 実装

- `engine_m6/decision_policy.py`：`policy_score` の6軸の加重合計は維持するが、`competitive_group` と `role` による固定減点（旧最大30点、暫定最大14点）を**撤廃**。`competing_selected`、`role_selected` は互換引数として残すが、結果に影響させない。
- `screened_choice`：同グループ・同役割の選択済み枚数の集計を採点へ渡さない。既存の `recommended_max` はカード別の最大採用枚数として有効。
- `engine_m6/recompose.py`：競争評価MAINの同点判定から役割目標数による優遇を削除。EXで同一カードの2枚目を自動12点減点する処理を削除。EXのテーマ優先／召喚方式検索段階と素材ゲートは維持。
- `TARGETS` は旧レガシーモードおよび構築診断の参考に残し、競争評価による選定で枚数目標として強制しない。
- 同名カード2・3枚目は`recommended_max`および実際のレアリティ・所持枚数・禁止制限上限に従う。現行システムでは`recommended_max`の**自動最適化は未実装**で、入力側の根拠ある枚数判断が必要。ゲームでの使用頻度・ダブり引きが弱いこと・サーチ可能性を確認する。

## テストと受入条件

カードの評価点が他カードの同役割採用枚数で変わらないこと、基本点が高い妨害札が低い他役割札に重複減点のみで逆転されないこと、同名カードの個別`recommended_max`上限を守ることを合成データで確認する。

既存M6-7のGen6軍貫実データを正式に再生成するには、MD固有の確認済み禁止制限データとGen6対応の教師資料が依然として必要。この変更だけで軍貫の最新デッキが正式に合法・最適となったとは宣言しない。

## 留保

6軸の`role_need`はなお採点に含む。これは候補カードの「当該デッキにおける必要性」という入力評価であり、採用済み枚数による機械的な減点ではない。ただし入力作成者がこの値に固定枚数ルールを紛れ込ませれば再発するため、レビューで役割バランスの機械的減点を用いない。
