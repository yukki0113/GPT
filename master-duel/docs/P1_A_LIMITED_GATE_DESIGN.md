# 限定P1-A 開始境界・受入設計（2026-11-09）

**本書は設計・ゲートであり実装開始のGOではない。** P0-B/P0-Cで確認できた技術的実現性を、無条件の著作権利用許諾やMD公式情報の保証に読み替えない。

## 優先目標

`UC-01`「SR以下の低コストテーマ発掘」を将来の主機能とし、先に`UC-04`などを支える**正確なカードIDと検索フィルタ**を整備する。パックの100%網羅を初期P1-Aの絶対条件にしない。完了版でパック情報が欠損する場合はUNKNOWNで明示する。

## 提案する二段階

### P1-A0（利用条件確定前に設計検討できる範囲）

- 公開Gitに保存可能な**schema / code contracts / 手書きの架空fixture / テスト設計**だけを対象とする。
- 入力表現: `source_snapshot_id`, `canonical_id`, `konami_id`, `en_name`, `ja_name_candidate`, `kind`, `attribute`, `level`, `rank`, `link`, `atk`, `def`, `rarity_source`, `rarity_checked_at`, `max_copies`, `banlist_effective_from`, `verification_state`。
- IDと日本語表示名の同一性は別。P0で判明した`Black Luster Soldier`（同名別カード）・複数パスコードをJOIN例外としてテスト。**名称からcanonical_idを生成しない**。
- 状態は`UNKNOWN`と`NOT_APPLICABLE`を別値にし、`UNVERIFIED_SOURCE`と`GAME_VERIFIED`を混ぜない。
- 禁止制限は発効日つきベクトルの**スナップショット**として保持。現在合法かどうかはゲームの適用日と規制版を照合できた場合にのみ確定。
- `craftable` は`YES|NO|UNKNOWN`。不明13,931件を暗黙trueにしない。`packs`も`UNKNOWN`を持つ。
- 本文は**現在の公開Git契約・架空テストデータには入れない**。意味検索・効果全文索引の実装は別途P1-A1の権利ゲート後に判定。
- コードを書き始める場合、既存の`tools/data-storage/README.md`を先に確認。どの正規化方法が有用かを調べてから選定。

### P1-A1（MD公式検証＋利用条件後に判断する範囲）

- 実データからのカード台帳生成と私的永続保存・全文索引。
- ゲーム内でのMDレアリティ/規制/名前/本文の層化照合を行い、結果を出典時点付きで採用。
- 収録パック・生成可否は、確認済み値と未確認値を厳格に区別して段階的に補完。
- source snapshot SHA・変換版・対応例外数・行数と再処理性を必須とし、**Drive原本→local検証→私的成果物保存**。公開Gitにカード原文や個人所持データを入れない。
