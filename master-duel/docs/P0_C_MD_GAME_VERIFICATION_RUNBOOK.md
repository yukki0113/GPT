## 2. ゲーム内確認手順（自動操作・通信解析なし）

1. MDゲームの**カード一覧／デッキ編集**を開き、ゲームバージョン・確認日時（JST）・デッキ形式（通常ランク等）を記録。
2. カード名検索し、同名異カード・未所持表示・禁止カード表示のフィルターを確認。カードが見えたら**ゲーム内日本語名とMDレアリティ（N/R/SR/UR）**を比較。
3. **効果本文**をゲーム内とMD JSONの候補文面で比較。全文スクショの外部公開は避け、照合結果は `MATCH` / `FORMAT_ONLY` / `WORDING_DIFF` / `UNABLE_TO_VERIFY` とし、差があれば**最大限小さな差分の説明**を記す。P効果とモンスター効果を混ぜない。
4. **禁止制限**は対象のゲーム内表示がある場合だけ `0/1/2/3` を確認。今回のvectorは **2026-11-05施行**であり、ゲーム内の適用日が異なるときは無条件比較禁止。イベント専用ルール・OCGルールと混同しない。
5. **生成可否**（カード生成ボタンの可否）と**入手方法**（現在表示・現在購入可能・過去収録）を別項目で観測。`releases` 未記載は入手不能を意味しない。未所持状態だけで生成可否を推定しない。
6. 検証用の成果物はカード名・CID・照合日時・結果区分・参照画面種別・差分理由を記録。必要な場合だけ画面の証跡を**ユーザー承認のDrive領域**に保存し、**公開GitのCSVにカード本文全文や個人の所持カード数を記載しない**。

### 確認値の規約

- 値の状態: `NOT_CHECKED`, `MATCH`, `FORMAT_ONLY`, `MISMATCH`, `NOT_VISIBLE`, `UNABLE_TO_VERIFY`, `NOT_APPLICABLE`。
- `banlist` はゲームのレギュレーション・適用日を必ず保持。vector不掲載を「無制限3枚」と評価する場合も**対象ゲームモードと現行規制の独立確認が必要**。
- `craftable` は`YES|NO|UNKNOWN`; `pack` は`LISTED|CURRENTLY_PURCHASABLE|EXPIRED|UNKNOWN`等とし、`MISMATCH`の解決前に確定判定へ昇格しない。
- 差があればカードIDの混線（同名異カード・別イラスト）とテキスト改訂日を先に調べる。未解決は`REVIEW_REQUIRED`に倒す。
