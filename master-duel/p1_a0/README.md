# P1-A0 synthetic contract probe

**架空データのみ**で動くカードID／MDレアリティ出典／禁止制限／UNKNOWNの検証器です。

Run from master-duel/p1_a0:

    python -m unittest discover -s tests -v

公開Gitに実カード原文・所持情報は保存しません。Drive原本の取得・変換、公式MD情報の保証、デッキ生成は行いません。
名前やパスコード別画像は論理カードのキーとしません。非公式禁止制限はゲーム内確認前に合法性として確定しません。
本ツールは標準Pythonのみで動作しDuckDB/Parquetを利用しないため、共有data-storage基盤への変更はありません。
P0-C公式ゲーム画面30件の検証は未実施、P1-A1はNO-GOを維持します。

## 2026-11-09 第2段: 条件検索・規制スナップショット

- `catalog_search.py`: 合成データの部分一致検索（NFKC/casefold/空白除去。元の日本語表記は保持）、レアリティ上限、種別、生成可否、入手経路、ゲーム内確認済み条件のANDフィルターを追加。
- `RegulationSnapshot`: デッキ形式（通常戦/イベント等）と施行日を区別し、対象日以前の最新スナップショットを選択。**同日競合・未検証の新版・カードID未掲載はUNKNOWNとしてfail-closed**。規制vectorにないカードを自動的に3枚扱いしない。
- `tests/test_catalog_search.py`: 追加20テスト。初回11テストと合わせて**31件PASS**。架空カードと架空規制だけを使用。MDゲーム画面の独立照合は0/30のまま。
- 実データ入力・効果文検索・コスト計算・合法性保証は対象外。

## 2026-11-09 第3段: スナップショット差分監査

- `snapshot_diff.py`: 架空の旧版・新版`Dataset`を比較し、追加・削除・フィールド変更・canonical/KONAMI ID再割当てを**監査候補**として返す。名前や別イラストのパスコードだけでIDを再結合しない。
- 同一snapshot IDを異なるSHAで再利用した場合、同じSHAを称する別の論理カード内容が検出された場合、入力を拒否。差分レポートハッシュは順序に依存しない決定的値。
- `diff_regulations`: 同一デッキ形式内で発効日・規制行を比較し、追加/消失/0-3値変更を区別。**規制一覧から消えたカードを無制限3枚にしない**。日付逆行、同一snapshot ID上書きを拒否。未検証新版はREVIEW_REQUIRED。
- **このモジュールは差分を出すだけで、更新・配布・昇格は実行しない。** 衝突ありの場合は上位の正式な受入処理で停止させること。
- `tests/test_snapshot_diff.py`: 追加16件。以前の31件と合計**47/47 PASS**（架空fixtureのみ）。実カード・ゲーム内30件確認は未実施。
