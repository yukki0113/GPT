マスターデュエル（以下 MD）収録カードの日本語台帳を基盤に、自然言語検索・低コストデッキ発掘・所持カード活用・出張パーツ提案を行う個人利用向け構築支援プロジェクト。

**状態**: 基本設計 v0.1（2026-11-09）。実装・データ収集は未着手。

## 目的

最優先ユースケースは「**SR以下で組めるお手軽テーマデッキは？**」。
単純なレアリティ足切りではなく、ユーザーの所持汎用カード、出張パーツ、MD禁止制限、EXデッキを考慮して、**新規生成が必要なURを0枚に抑えられる構築**を探す。

その他、「ドローできるカード」「特定テーマをサーチできるテーマ外カード」「デモンスミス／スピードロイド／壊獣等の出張候補」も扱う。
