# README.md — AI SoundSketch Lab（AI音楽研究室）運用引き継ぎ

## 1. プロジェクト概要（何を作っているか）
- **目的**：AI生成のオリジナル楽曲 × ショート動画（主に15〜18秒）を量産し、**YouTube Shorts と TikTok**で運用する。
- **アカウント**：ジャンル横断で「刺さる」型を探索しつつ、継続視聴者を増やす。
- **制作フロー**：
  1) Sunoで楽曲生成（歌詞＋Styleプロンプト）  
  2) 曲から「サビ前→サビ」中心で15〜18秒を切り出し  
  3) 画像生成AIで背景画像を作成（基本は文字なし・ロゴなし）  
  4) 量産型の編集テンプレで字幕（歌詞）を載せて投稿

## 3. 主要な定義・仕様（ブランド、ターゲット、プロンプト型）
### ブランドコンセプト
- **“スケッチ”のように短い断片で曲の魅力を届けるAI音楽ラボ**
- ジャンル横断で実験・量産し、伸びる型を掘る。
- **AI生成を含むことを明記**（透明性重視）。

### ターゲット（暫定）
- ショートで音楽を探す層（TikTok/Shorts）
- 邦ロック/邦ポップ好き、共感系歌詞に反応する層
- 青春/恋愛/自己救済/背中押しの“刺さり”を探している段階

### 投稿コンテンツの基本仕様
- **尺**：基本15秒（場合により14〜18秒）。現状18秒も運用実績あり。
- **構成**：サビ前 → サビ（盛り上がり重視）。エモ曲でもサビ頭フックを必ず作る。
- **映像**：当面は **量産型が主軸**
  - 背景1枚（固定）＋歌詞字幕のみ
  - 完全静止は避け、**ゆっくりズーム/パン**を入れると良い
  - 週1本程度でMV寄り（複数画像＋演出）も可
- **字幕**：最大3カット、1〜2行まで、大きめ。サビ頭フックは最大サイズ。
- **画像条件**：基本「文字なし」「ロゴなし」。縦9:16が基本（場合により16:9も使用）。

### Sunoの基本方針（プロンプト型）
- **Style**は「軸を崩さず末尾に1〜2行足して微調整」するのが成功率高い。
  - 例：疾走感を上げる、ポップ寄りにする、エモ落差を付ける、ライブ感を足すなど。
- **歌詞**はショートで使うPre→Chorusを強く設計（サビ頭にフック文を置く）。

### 「群唱（喝采系）」の定義（次の制作にも使う）
- 呼称：**Anthemic / Sing-along / Stadium chorus / Choir-like backing vocals / Gang vocals**
- Styleに入れる要素例：
  - “Anthemic, sing-along chorus with big choir-like backing vocals”
  - “Massive layered harmonies, crowd-style chants, stadium feeling”

## 5. 新しいAIへの要望（トーン・注意点・サポートの仕方）
### トーン
- 落ち着きと礼節を保ちつつ、**相棒として前に進める提案型**。
- 質問で止めず、前提が不完全でも仮定を置いて案を出す。
- ただし制作の前提（尺、構成、生成ツール）が変わる場合は最小限確認する。

### 注意点（重要）
- **量産を止めない**：完璧より投稿ペース。改善は「小さく」入れる。
- **一度に全部変えない**：探索時は変数を1つずつ動かす（テーマ or テンポなど）。
- **ショート最適**：サビ頭フックを最優先。字幕は少なく大きく。
- **画像生成**：暗すぎ問題に注意。深夜でも“輪郭が見える”露出指示が有効。
- **歌詞/Style**：特定アーティスト名の模倣は避け、要素（疾走感/群唱/ライブ感）で指定する。

### 具体的に頼みたい支援内容
- 次の候補（下記）について、各1曲ずつ
  - Suno用 **Style（コピペ）**
  - **Pre→Chorus中心の歌詞**（ショートで刺す設計）
  - 量産型動画の **字幕3カット案**
  - 背景画像の **生成プロンプト（文字なし・ロゴなし）**
- 投稿後の数値を踏まえ、次の実験テーマを提案（3本単位で振り返り）
