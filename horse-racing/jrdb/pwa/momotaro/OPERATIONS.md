# 桃太郎新聞 運用指示

## 目的

桃太郎新聞に掲載する3人予想と共通外部参考情報の提出・整形・表示ルールを定義する。

対象メンバー:

- りょーた
- おーじ
- けんしょー

共通外部参考:

- 🐬 イルカブログ

この文書を桃太郎新聞の予想運用正本とする。

## 基本単位

提出・取り込みは開催日単位で行う。

1日分のデータをまとめて受領し、日付・開催・R・馬番・馬名をJRDB/PACI側とexact joinする。

馬名や対象Rを推測して補完しない。不一致は未結合として監査対象に残す。

## りょーた

### 通常予想

原則として予想対象日の各Rについて印を受領する。

想定入力:

- 日付
- 開催
- R
- 馬番
- 馬名
- 印

新聞では、りょーた列に各Rの印をそのまま表示する。

通常印は一覧画面への掲載条件にはしない。新聞本体の印欄が主表示となる。

### 特注馬

通常印とは別に、りょーたが指定した特注馬を扱う。

想定入力:

- 日付
- 開催
- R
- 馬番
- 馬名
- 特注区分
- コメント

特注馬は通常印と混同しない。

表示:

- 新聞のりょーた印欄では、対象馬の印をリンク化する
- リンクから特注コメントを表示する
- 予想一覧にも掲載する
- 予想一覧では source を「りょーた」として表示する

現行schemaでは、特注フラグは `review_horse=true` を使用する。
`confidence=S` は自信度Sという別概念として保持し、特注馬と同義にはしない。

将来、特注区分が複数必要になった場合は専用fieldへの拡張を検討する。

## おーじ

おーじは毎Rの通常印を必須としない。

回顧から抽出した該当馬のみを受領する。

想定入力:

- 日付
- 開催
- R
- 馬番
- 馬名
- 回顧コメント

内部表現:

- `addons.momotaro.oji.review_horse = true`
- `addons.momotaro.oji.comment = <回顧コメント>`

表示運用は🐬と同じ思想とする。

- 新聞の王子列で対象馬だけリンク化
- リンクから回顧コメントを表示
- 予想一覧にも掲載
- 非対象馬は空欄

おーじの通常印を将来受領する場合でも、回顧該当馬とは別概念として扱う。

## けんしょー

現時点では運用保留とする。

RaceNoteの予想運用が完成した時点で、桃太郎新聞へ載せる情報源と表示ルールを再決定する。

暫定案としてJRDB既存印をけんしょー列へ転記する案はあるが、正式決定ではない。

したがって、現時点では以下を行わない。

- JRDB印を自動的にけんしょー予想として確定する
- RaceNote未完成の状態で独自入力を必須化する

正式決定までは空欄を許容する。

## 🐬 イルカブログ

🐬は3人の予想とは別の共通外部参考情報。

内部表現:

- `addons.keibailuka`

表示:

- 新聞の🐬列で対象馬のみリンク化
- リンクからブログ由来コメントを表示
- 予想一覧にも掲載
- 非対象馬は空欄

3人の `addons.momotaro` へコピーしない。

## 新聞表示

印列:

- りょ
- 王子
- けん
- 🐬

意味:

- りょ: りょーたの各R通常印。特注馬はリンク化
- 王子: おーじ回顧該当馬のみ表示・リンク化
- けん: 保留。正式運用決定まで空欄可
- 🐬: イルカブログ対象馬のみ表示・リンク化

過去走は5走固定。表示は個人PWAと共有する `newspaper-v4` compact rendererを使用する。

過去走の情報量・セル構造は桃太郎側で複製せず、共有runtimeを正本とする。桃太郎固有差分は5走固定と予想4列に限定する。

運用用の取得状態、source status、手動取込UIは桃太郎側では表示しない。

## 予想一覧

レース単位で1カードにまとめる。

同一レースで複数sourceが該当する場合はsource単位で縦に積む。

表示例:

```text
中山 7R

🐬
7番 ユアフェリシティ
前走は前しんどい展開で前潰し。

りょーた
2番 ○○○○：特注
コメント

王子
5番 △△△△：回顧馬
コメント
```

一覧対象:

- りょーた特注馬
- おーじ回顧該当馬
- 🐬対象馬

通常のりょーた各R印は一覧へ全件展開しない。

けんしょーは正式運用決定まで一覧対象外。

## addon contract

```json
{
  "addons": {
    "momotaro": {
      "ryota": {
        "mark": "◎",
        "confidence": null,
        "review_horse": true,
        "comment": "特注コメント"
      },
      "oji": {
        "mark": null,
        "confidence": null,
        "review_horse": true,
        "comment": "回顧コメント"
      },
      "kenshow": {
        "mark": null,
        "confidence": null,
        "review_horse": false,
        "comment": null
      }
    },
    "keibailuka": {
      "comment": "ブログ由来コメント"
    }
  }
}
```

欠損値は推測せず空扱いとする。

## 変更管理

この運用を変更する場合は、以下を同時に確認する。

- 入力フォーマット
- `addons.momotaro` contract
- 新聞表示
- 予想一覧
- 桃太郎公開projection
- focused tests

個人PWAのKenshow_Labo側へ桃太郎固有ルールを波及させない。
