# 桃太郎新聞 運用指示

## 目的

桃太郎新聞に掲載する3人予想と共通外部参考情報の提出・整形・表示ルールを定義する。

対象メンバー:

- りょーた
- おーじ
- けんしょー

共通外部参考:

- 🐬 イルカブログ

この文書を桃太郎新聞の予想運用正本とする。

## 基本単位

提出・取り込みは開催日単位で行う。

1日分のデータをまとめて受領し、日付・開催・R・馬番・馬名をJRDB/PACI側とexact joinする。

馬名や対象Rを推測して補完しない。不一致は未結合として監査対象に残す。

## りょーた

### 通常予想

原則として予想対象日の各Rについて印を受領する。

想定入力:

- 日付
- 開催
- R
- 馬番
- 馬名
- 印

新聞では、りょーた列に各Rの印をそのまま表示する。

通常印は一覧画面への掲載条件にはしない。新聞本体の印欄が主表示となる。

### 自信度付き予想

レース単位で自信度が付いた場合、そのレースの◎馬に自信度を保持する。

表示:
- 自信度はレース評価のメタデータとして保持するが、**自信度だけで印をリンク化しない**
- 馬単位の短評・回顧コメントがある馬の印だけをモーダル化する
- モーダルでは対象馬の短評と、存在する場合のみ自信度・次走注目タグを表示する
- 予想一覧にも**馬単位のコメントがある馬だけ**を掲載する（印の種類や自信度は条件にしない）
- レース全体の【見解】はレース短評欄へ表示し、馬ごとのコメントに自動複製しない

### 特注馬

通常印とは別に、りょーたが指定した特注馬を扱う。

想定入力:

- 日付
- 開催
- R
- 馬番
- 馬名
- 特注区分
- コメント

特注馬は通常印と混同しない。

表示:

- 新聞のりょーた印欄では、対象馬に馬単位コメントが存在する場合だけ印をリンク化する
- リンクから次走注目ランク（次走S/A等）とコメントを表示する
- 予想一覧にも掲載する
- 予想一覧では source を「りょーた」として表示する
- 同じ馬にレース自信度と次走注目ランクの両方がある場合は、両方を併記する

現行schemaでは、特注フラグは `review_horse=true` を使用する。
次走注目ランクは `tag=次走S` / `tag=次走A` 等で保持する。
`confidence` は当日予想の自信度という別概念として保持し、次走注目ランクと同義にはしない。

将来、特注区分が複数必要になった場合は専用fieldへの拡張を検討する。

## おーじ

おーじは毎Rの通常印を必須としない。

回顧から抽出した該当馬のみを受領する。

想定入力:

- 日付
- 開催
- R
- 馬番
- 馬名
- 回顧コメント

内部表現:

- `addons.momotaro.oji.review_horse = true`
- `addons.momotaro.oji.comment = <回顧コメント>`

表示運用は🐬と同じ思想とする。

- 新聞の王子列で対象馬だけリンク付きの○を表示
- リンクからコメントを表示
- 予想一覧にも掲載
- 非対象馬は空欄
- おーじは提出内容がすべて回顧由来のため、画面上で「回顧馬」等の区分ラベルは重ねて表示しない

おーじの通常印を将来受領する場合でも、回顧該当馬とは別概念として扱う。

## けんしょー

けんしょーはKenshow_Labo利用者本人であり、RaceNote / RaceReviewDB (RRDB) を予想・短評・注目馬提出の正本とする。

### RaceNote

RaceNoteの当日予想を、そのままけんしょー予想として扱う。

自動変換:

- RaceNote印 → `addons.momotaro.kenshow.mark`
- RaceNote confidence → `addons.momotaro.kenshow.confidence`
- RaceNote単馬短評 → `addons.momotaro.kenshow.comment`
- RaceNoteレース短評 → `race_notes.momotaro_comments.kenshow`（個人PWAでも独立RaceNote短評欄は持たず、けんしょーの「短評」欄へ表示）
- 画面表示用tagは付けない

新聞ではRaceNote印を「けん」列に表示する。
単馬短評がある場合は印セルから詳細を確認できる。
レース短評は新聞下部のけんしょー短評として表示する。

### RaceReviewDB (RRDB)

RRDB推薦に該当した馬は、けんしょーの注目馬提出として扱う。

自動変換:

- RRDB推薦該当馬 → `addons.momotaro.kenshow.review_horse = true`
- RRDB recommendation_comment → `addons.momotaro.kenshow.comment`
- 画面表示用tagは `不利分析`

RaceNoteとRRDBが同一馬に重なった場合:

- 印・confidenceはRaceNoteを使用
- 新聞のけん列はRaceNote印をそのままモーダル化する
- RaceNote印が無いRRDB該当馬は「注」を表示してモーダル化する
- RRDB該当時のモーダル本文はRRDBコメントだけを表示する
- 画面表示用tagは `不利分析`
- RRDB該当なので `review_horse=true`

### 手動補正

明示的なけんしょー手動入力がある場合は自動変換値より優先する。
ただし未指定fieldはRaceNote/RRDB自動値を維持する。

`tag=手動無印` の場合のみ、RaceNote由来の印も含めて印を明示的に空にする。

### 旧暫定仕様

JRDB総合印をけんしょー印へ転記する旧暫定仕様は廃止する。
JRDB印とけんしょー予想は別概念として扱う。

### 反映先

- RaceNote: 桃太郎新聞・個人PWA新聞のけん列 / レース短評。単馬コメントは新聞モーダルのみ。
- RRDB: 桃太郎新聞・個人PWA新聞のけん列モーダル + 両PWAの注目馬一覧。

## 🐬 イルカブログ

🐬は3人の予想とは別の共通外部参考情報。

内部表現:

- `addons.keibailuka`

表示:

- 新聞の🐬列で対象馬のみリンク化
- リンクからブログ由来コメントを表示
- 予想一覧にも掲載
- 非対象馬は空欄

3人の `addons.momotaro` へコピーしない。

## 新聞表示

新聞ページには3人分をまとめた短評カードを置かない。各コメントは該当印セルのモーダルで確認し、横断的な確認は予想一覧を使う。

印列:

- りょ
- 王子
- けん
- 🐬

意味:

- りょ: りょーたの各R通常印。馬単位短評・回顧コメントがある馬のみリンク化
- 王子: おーじ回顧該当馬のみ表示・リンク化
- けん: RaceNote印を表示。RaceNote/RRDB短評・注目馬はけんしょー情報として扱う
- 🐬: イルカブログ対象馬のみ表示・リンク化

過去走は5走固定。表示は個人PWAと共有する `newspaper-v4` compact rendererを使用する。

過去走の情報量・セル構造は桃太郎側で複製せず、共有runtimeを正本とする。桃太郎固有差分は5走固定と予想4列に限定する。

運用用の取得状態、source status、手動取込UIは桃太郎側では表示しない。

## 予想一覧

レース単位で1カードにまとめる。

同一レースで複数sourceが該当する場合はsource単位で縦に積む。

表示例:

```text
中山 7R

🐬
7番 ユアフェリシティ
前走は前しんどい展開で前潰し。

りょーた
2番 ○○○○：特注
コメント

王子
5番 △△△△
コメント
```

一覧対象:

- りょーたの馬単位短評・回顧コメントが存在する馬（自信度のみでは掲載しない）
- おーじ回顧該当馬
- 🐬対象馬

通常のりょーた各R印は一覧へ全件展開しない。

けんしょーはRRDB該当馬だけを注目馬一覧へ掲載する。RaceNote単独馬は一覧対象外。表示タグは「不利分析」。

## addon contract

```json
{
  "addons": {
    "momotaro": {
      "ryota": {
        "mark": "◎",
        "confidence": null,
        "review_horse": true,
        "comment": "特注コメント"
      },
      "oji": {
        "mark": null,
        "confidence": null,
        "review_horse": true,
        "comment": "回顧コメント"
      },
      "kenshow": {
        "mark": null,
        "confidence": null,
        "review_horse": false,
        "comment": null
      }
    },
    "keibailuka": {
      "comment": "ブログ由来コメント"
    }
  }
}
```

欠損値は推測せず空扱いとする。

## 個人PWA専用の印モーダル判定

桃太郎PWAの `momotaro/momotaro.js` と個人PWAの `newspaper-momotaro.js` は別実装であり、両者を必ず同時確認する。

- りょーたの通常印・レース自信度・タグ・回顧フラグだけでは印をリンク化しない。
- `addons.momotaro.ryota.comment` が空白を除いて非空の場合のみ、個人・桃太郎の両新聞で印をモーダル化する。
- 注目馬一覧も馬単位コメントの存在で判定する。レース全体の見解は馬単位コメントとみなさない。
- Pages更新時は個人 `newspaper.html` の `newspaper-momotaro.js` バージョン、両Service Workerのキャッシュ世代、focused testを合わせて確認する。
- テストではconfidenceのみ存在する通常印がリンク化されないことを必ず検証する。

## 変更管理

この運用を変更する場合は、以下を同時に確認する。

- 入力フォーマット
- `addons.momotaro` contract
- 新聞表示
- 予想一覧
- 桃太郎公開projection
- focused tests

個人PWAは桃太郎公開情報を伴走データとして取り込み、けんしょー情報も同一意味で新聞・注目馬一覧へ反映する。
