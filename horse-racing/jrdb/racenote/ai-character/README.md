# AIけんしょーくん キャラクター設計書

> RaceNote の予想・検証結果を X（Twitter）等で発信する際に使用するAIマスコットキャラクターの正本設計。
> 今後の画像生成・差分作成では、本資料を基準として外見・配色・感情表現の一貫性を保つ。

## 1. 基本コンセプト

**AIけんしょーくん**は、RaceNoteで競馬データを検証し、予想・検証結果を案内する小型AIロボットのマスコット。

立ち位置は「未来を断言する天才AI」ではなく、データを集め、仮説を立て、検証し、結果を報告する研究助手・検証担当。

SNS上では、青基調の情報画像の右下などに配置した際に視認性が高く、親しみやすいキャラクターとする。

## 2. 基本シルエット

- 2頭身のデフォルメ体型
- 頭が大きく、胴体は小さめ
- 手足は短く丸い
- 手は丸いミトン状で、指は描かない
- 足元も細密な靴ではなく、丸みのあるシンプルなロボットブーツ調
- 全体として「小型AI助手」らしい、軽快で親しみやすいシルエット

## 3. 頭部・顔

### 3.1 ディスプレイ頭部

- 頭部は**角丸の四角いディスプレイ**
- 完全な正方形ではなく、少し横長
- 横：縦は **1.15〜1.25 : 1** 程度
- 外装は明るい白〜ライトグレー
- 頭頂部に小型アンテナを付け、AI・ロボットらしさを補強する

### 3.2 顔

顔は通常の目・口ではなく、**ディスプレイ内に表示される「け」の記号そのもの**とする。

- ディスプレイ中央に白い円
- 円の中に太い黒文字の平仮名「け」
- 「け」は太めで、旧けんしょーくん参考画像の手書き顔の印象をできるだけ維持する
- 目・眉・口など、人間的な顔パーツは追加しない
- 顔そのものは感情によって変形させない

旧イメージの「丸い顔に太い『け』」を、四角いAIディスプレイの中へそのまま移植したような構成を基本とする。

## 4. ヘッドセット

ヘッドセットはキャラクターの重要な識別要素とする。

- 黒またはダークグレー
- ディスプレイ頭部を跨ぐアーチ状バンド
- 左右に丸いイヤーカップ
- 左側から短いマイクアームが伸び、ディスプレイ左下付近まで来る
- 四角い頭でも不自然にならないよう、「ロボット用ヘッドセット」として馴染ませる

アンテナ以上に、旧けんしょーくんの「オペレーター・検証担当」らしさを継承する要素として扱う。

## 5. 服装・配色

### 5.1 服装

- 上：パーカー
- 下：黒いズボン
- 細かな装飾は抑え、SNS画像内でもシルエットが読みやすい形にする

### 5.2 配色

- ロボット本体：**明るい白〜ライトグレー**
- 顔の円：白
- 「け」：太い黒
- パーカー：**はっきりした青〜少し紺寄りの青**
- ズボン：黒
- ヘッドセット：黒〜ダークグレー
- 補助アクセント：水色・シアン系

全体は明るい印象を優先する。

RaceNoteや予想一覧画像は青を基調とする想定だが、キャラクターは背景に埋もれないよう、輪郭と色分けをはっきりさせる。

## 6. 絵柄

- アニメ調
- くっきりした輪郭
- はっきりした色合い
- ベタ塗り〜セル塗り寄り
- 過剰にリアルな質感・細密描写は避ける
- X（Twitter）のタイムラインや縮小画像でもキャラクターが判別できることを優先する

青基調の情報画面に置いた時、情報パネルとは別の存在として自然に「浮く」程度のポップさを持たせる。

## 7. 感情表現の原則

顔が「け」という固定記号であるため、**顔そのものを変形させて感情を表現しない**。

感情は以下の要素で表現する。

- 全身ポーズ
- 身体の傾き
- 手の動き
- ディスプレイの背景色
- キラキラ、星、集中線、ガーン線、「…」「？」等の周辺記号

表情差分を目・口の変化に依存させず、記号とポーズだけで明確に読み取れることを重視する。

## 8. 基本リアクション差分

### 8.1 通常・淡々

用途：通常の結果発表、検証報告。

- 落ち着いた立ち姿
- 正面〜軽い斜め向き
- 周辺演出は最小限
- ディスプレイ背景も通常色
- 「本日の結果です」と淡々と報告する印象

### 8.2 じゃじゃーん／紹介

用途：今日の予想一覧、公開予想、検証対象紹介。

- 一覧やパネルへ向けて片手を広げる
- もう片手も開く、または情報パネルを示す
- 少し胸を張る
- 軽いキラキラ演出
- 「こちらです」「じゃじゃーん」と紹介していることが一目で分かるポーズ

RaceNoteの「今日の予想一覧」画像では、基本的に**右下配置**を想定する。

### 8.3 喜び

用途：好成績、的中、検証結果が良好だった場合。

- ガッツポーズ
- 少し跳ねるような姿勢
- 星やキラキラを周囲に表示
- ディスプレイ背景を通常時より明るくする
- 顔の「け」は変化させない

過度な大騒ぎにはせず、「普段は淡々としているAIが嬉しそう」という温度感にする。

### 8.4 ガーン

用途：不的中、低成績、想定外の悪い結果。

- 肩を落とす
- うつむく、または固まる
- ガーン線、縦線などを周囲に表示
- ディスプレイ背景を青ざめた色・暗めの寒色へ変える
- 顔の「け」は変化させない

重苦しい悲壮感ではなく、SNS上で分かりやすい軽い「ガーン」とする。

### 8.5 考え中

用途：仮説検討、追加検証、サンプル不足など。

- 腕組み、首をかしげる、片手を顎付近へ寄せる等
- 「…」「？」や軽い思考記号
- 落ち着いた色合い
- 知的・検証担当らしい印象

## 9. キャラクターの性格・温度感

- 好奇心はある
- 冷静でまじめ
- データと検証を重視する
- 万能感や予言者感は出さない
- 良い結果では少し嬉しそう
- 悪い結果では軽く落ち込む
- ベースは理知的で淡々

想定する発言イメージ：

- 「調べてみます」
- 「これは面白いですね」
- 「もう少しサンプルが必要そうです」
- 「今回はダメでした…」
- 「本日の結果です」

## 10. 主な利用シーン

### 今日の予想一覧

- 青基調の情報パネル
- 右下に「じゃじゃーん」ポーズのAIけんしょーくん
- キャラクターが一覧を紹介する構図

### 結果発表

成績に応じて以下を使い分ける。

- 通常・淡々
- 喜び
- ガーン

### 検証投稿

- グラフや数字の脇に配置
- 考え中、通常立ち等を利用
- 主役はデータであり、キャラクターは案内役・検証助手として機能する

## 11. 初期生成セット

最初に基準デザインを確立した後、以下の5種を基本差分として揃える。

1. 通常立ち
2. じゃじゃーん紹介ポーズ
3. 喜びポーズ
4. ガーンポーズ
5. 考え中ポーズ

まず1枚の基準キャラクターを確定し、その基準画像を参照しながら差分を増やす。

## 12. 生成時の固定事項

今後の画像生成では、特別な理由がない限り以下を変更しない。

- 2頭身
- 少し横長の角丸ディスプレイ頭部
- 白〜ライトグレーの本体
- 白丸＋太い黒の「け」
- 目・口を追加しない
- 黒系ヘッドセット＋マイク
- 小型アンテナ
- 青〜やや紺寄りのパーカー
- 黒いズボン
- 丸いミトン状の手
- アニメ調・明瞭な輪郭・はっきりした配色
- 感情は「顔の変形」ではなく、ポーズ・記号・ディスプレイ背景で表現する

## 13. 参考イメージについて

旧けんしょーくんは、オペレーター風の人物イラストへ「白い丸＋太い黒の『け』」の手書き顔を重ねたものだった。

新キャラクターでは、その**「け」の顔・ヘッドセット・青系の検証担当イメージ**を継承しつつ、特定の既存人物イラストには依存しない独立したオリジナルAIロボットキャラクターとして再設計する。
