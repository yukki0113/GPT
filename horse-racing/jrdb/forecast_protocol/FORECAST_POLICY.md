# 予想方針

## 1. 対象期間・サンプル抽出方針

- **対象期間**：予想対象年の前年までの**過去10年間**（暦年単位）。
  - 例：**2026年のレースを予想する場合は2016〜2025年**のデータを使用する。
  - 予想対象年が変わる場合も同様に対象期間を更新する（例：2027年なら2017〜2026年）。
- 指定レースが名称を持つ特別競走（例：有馬記念、フェアリーステークス、姫路特別）の場合、原則として**同名・同条件の過去レース**をサンプルに採用する。
  - 「同条件」とは、コース、距離、芝・ダート、クラスなどの施行条件が一致することを指す。
- 同名・同条件のレースが存在しない、または**該当サンプルが4件以下**の場合は、その事実と件数を明記したうえで、**施行条件を可能な限り一致させた類似レース**を追加する。
  - 類似レースの選定では、上記条件に加えて施行時期、性齢限定なども考慮し、条件の再現度を最大限高める。
  - **同名・同条件のサンプルと補完した類似レースは区別して示す。**

> **期間の基準**：予想対象年自身のデータは含めず、前年までの10暦年を使用する。

## 2. 統計の検索条件

抽出した過去レースについて、以下の項目と好走実績との関係を確認する。

- 人気
- 枠順
- 脚質
- 馬齢
- 血統
- 騎手
- 前走距離
- 前走クラス

## 3. 予想ロジック

1. **PACIから各馬の情報を取得する。**
   - 各馬の基本情報
   - 前走1走分の内容
2. **過去レースの統計傾向を主軸に評価する。**
   - 対象レースに近い条件で、好走回数が多かった検索条件を特定する。
   - 各馬がその条件にどれだけ合致するかを中心に予想を組み立てる。
3. **個別事情を確認し、最終調整する。**
   - 前走の内容と相手関係
   - 前走で受けた不利
   - 当該馬の実力指数、コース適性など
   - これらは**統計予想を補足・調整する材料**であり、原則として主軸を置き換えない。

### 印の付け方に関する考え方

- ◎は単純な総合点の最高評価馬ではなく、**そのレースの条件と予想根拠を踏まえて、最も買いたい馬**を示す。
- 明確な軸馬が不在の場合も、その不確実性を認識したうえで印や買い目を検討する。
- 懸念点があることだけを理由に、候補馬を機械的に除外しない。

## 4. この予想法の基本思想

統計学上、サンプル数が少ない分析には限界があることを認識する。そのうえで、あえて**同名・同条件、または施行条件の再現度を極限まで高めたレース**に対象を絞り、レース固有の傾向を捉える。

**サンプル数の多さよりも、条件の一致度・再現性を優先する。** 予想の中心はあくまで過去の好走傾向とし、前走内容・不利・実力指数などは最終調整に用いる。
