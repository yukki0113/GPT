# JPDB R2 — 相対条件傾向研究の事前固定プロトコル v0.1 (2026-11-24)

研究用、予想投入不可。R1固定世代・2023–2026-11-15を使用する。R1の個別レース出力は変えず別の比較sidecarを作る。予定騎手はR1、履歴は実騎乗者。R1の全条件を保持し、全平地は他騎手比較のみ、対象馬場未知等は比較不能。距離帯・脚質・初騎乗/継続騎乗は別途定義が必要な研究候補であり本工程で自動分類しない。

## 比較単位

- 4群: 本人・対象条件(A)、本人・同じ親条件内の他条件(B)、本人以外・対象条件(C)、本人以外・同じ親条件内の他条件(D)。互いに排他的。全平地にはB/Dがない。競馬場×芝ダ・芝ダ×距離は同芝ダ内、新馬戦×芝ダはA1内、新馬戦×競馬場/距離はA1かつ同芝ダ内、class×surfaceは同芝ダ内、その他のR1軸は全平地内（物理属性は既存P2の母集団を維持）。A1全体と非A1の比較は平地全体。未知条件は他条件に数えない。peerは本人以外の全有効騎手の騎乗単位集計であり騎手均等重みではない。
- 主要指標は3着内率、補足は勝率。A-B（本人内）、A-C（同条件peer）、(A-B)-(C-D)（相対条件コントラスト）。最後は記述的交互差であり因果推定ではない。単一総合スコア、ランキング、加点禁止。
- R1/P1の結果分類を再利用。正常完走+DNFの解決済み出走を分母とし、取消/除外は非出走、降着5/不正着順/未知は未解決のまま別計数。解決済み集団率はR1候補率の代用品ではない。未解決の全件が出走して失敗/成功した場合の保守的上下界を併記。本人比較対象に未解決が1件でもあれば方向保留。peerの未解決は境界に反映。各使用群に解決済み30騎乗以上が必要（記述用、検出力保証なし）。
- 方向は3着内率差の未解決感度境界が全て+5pp以上なら POSITIVE、全て-5pp以下なら NEGATIVE、全て(-5,+5)pp内なら NEAR_ZERO、それ以外は UNCLASSIFIED。5ppは研究上の事前固定表示幅であり等価性や有意性の認定ではない。各窓を独立加算しない。3Y/365D/90Dで支持のある正負両方向が出れば CONFLICTED。比較種別ごとに扱い、本人内とpeer比較を混ぜない。0件/未知/小母数/未解決を不得意に変換しない。
- 比較はCONTEXTUAL上限。信頼区間・多重検定の独立性/馬単位反復を含む統計的認証は別研究。今回は個別有意性検定を行わず、多数軸から好成績を抽出して能力と呼ばない。SUGGESTIVE認定は行わない。R1 redundancy_group_idと全騎手Evidence非加算を保持。

## 時系列再現性（評価前に固定）

全騎手×対象軸の候補を2023–24年の各1/1–11/15だけで列挙。2025、2026年の各1/1–11/15を別ホールドアウトとして比較（2026最終日もこの回顧研究では含む）。訓練窓の4群各n>=30、本人未解決なし、相対条件コントラストの方向POSITIVE/NEGATIVEを抽出する。評価窓の未観測・小母数・保留を除外して成功率を飾らず、選定全数と各状態・方向一致/逆転/中立を記録。両年一致を別集計。全平地・未知馬場を除くR1軸を対象とし、新馬軸のclassはA1のみ。結果を見た閾値・軸・年度の変更は禁止。重複軸の件数は独立な検定数ではない。ここでの方向再現は予想効果ではない。

## 馬質感度（非公開研究lane）

既存P3の正本市場基準（最終オッズ逆数を実出走馬内で正規化、結果/オッズ不正レース除外）を再利用。2023–24、2025、2026同一季節窓で、選定した軸の4群のraw勝率差と market_p を引いた勝利残差の相対条件コントラストを同一の受入コホート上で比較。対象軸は SURFACE, VENUE_SURFACE, SURFACE_DISTANCE_EXACT, NEWCOMER_ALL_FLAT, NEWCOMER_SURFACE, NEWCOMER_VENUE_SURFACE, NEWCOMER_SURFACE_DISTANCE_EXACT。各群n>=30。補正前後の符号一致/逆転と相関を全集計する。市場は騎手評価も含むため、馬質を完全分離したものではない。対象レースごとのsidecarには最終オッズ/市場期待値/市場残差を一切入れない。公開は匿名集計結果のみ。個別方向はR2記述値であり予想投入不可。
