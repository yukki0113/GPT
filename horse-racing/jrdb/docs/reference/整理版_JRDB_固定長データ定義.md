# JRDB 固定長データ定義

> Project Sources参照用の整理版。JRDB公式仕様原本8ファイルをCP932からUTF-8へ正規化し、1ファイルに統合したもの。
> 項目名・OCC・BYTE・TYPE・相対位置・備考・注記・改版履歴は原本記載を保持する。コード値の意味そのものは別途「JRDB マスタコード定義」に集約する。

## 1. 収録仕様一覧

| ファイル | 内容 | レコード長 | 扱い |
|---|---|---:|---|
| KYI | 競走馬データ | 1024 BYTE | 固定長本体 |
| BAC | 番組データ | 176 BYTE | 固定長本体 |
| CHA | 調教本追切データ | 64 BYTE | 固定長本体 |
| CYB | 調教分析データ | 96 BYTE | 固定長本体 |
| SED | 成績データ | 376 BYTE | 固定長本体 |
| SKB | 成績拡張データ | 304 BYTE | 固定長本体 |
| ZED | 前走データ | SED仕様参照 | データフォーマット・内容は成績データと同一 |
| ZKB | 前走拡張データ | SKB仕様参照 | データフォーマット・内容は成績拡張データと同一 |

## 2. 固定長共通ルール

- `OCC`：繰り返し定義
- `BYTE`：項目長
- `TYPE 9`：数字（0のとき0）
- `TYPE Z`：数字（0のとき空白）
- `TYPE X`：文字
- `TYPE F`：16進数（数字または小文字アルファベット）
- 数字項目にはマイナス記号を含む場合がある。
- 多くの仕様でレースキーは「場コード・年・回・日・R」を基本構成とする。
- `日` は2006年11月7日の競馬法施行規則改正対応後、TYPE Fの1桁で扱われる仕様がある。

## 3. 参照関係

- `ZED`（前走データ）は、原本上「データフォーマット、データ内容は成績データと同様」とされているため、実フィールド定義は `SED` を参照する。
- `ZKB`（前走拡張データ）は、原本上「データフォーマット、データ内容は成績拡張データと同様」とされているため、実フィールド定義は `SKB` を参照する。
- `SKB` 内の特記・馬具・脚元等の意味はコード表参照。
- `KYI`・`SED`・`BAC` 等で参照されるJRDB共通コードの値は別資料「JRDB マスタコード定義」を参照する想定。
