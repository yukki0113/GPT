# JRDB マスタコード定義

> Project Sources参照用の整理版。JRDB公式コード表7ファイルをCP932系からUTF-8へ正規化し、1ファイルに統合したもの。
> コード値・名称・説明・注記・更新履歴は原本記載を保持する。固定長上のBYTE・TYPE・相対位置は別資料「整理版_JRDB_固定長データ定義.md」を参照する。

## 1. 収録コード表

| 区分 | 原本内容 | 主な用途 |
|---|---|---|
| JRDB | JRDBデータコード表 | 脚質、距離適性、上昇度、調教矢印、厩舎評価、蹄、重適性、クラス、場、馬場状態、種別、条件、記号、重量、グレード、異常区分、コース取り、馬体、気配、印、毛色、馬記号、展開記号、天候、休養理由など |
| CYOKYO_COURSE | 調教コースコード表 | 調教コース識別 |
| OI | 追い状態コード表 | 調教時の追い状態 |
| KEITO | 系統コード表 | 血統の小系統・大系統 |
| TOKKI | 特記コード表 | レース・馬状態等の特記事項 |
| ASHIMOTO | 脚元コード表 | 脚元全体・各脚の状態 |
| BAGU | 馬具コード表 | ハミ、その他馬具、蹄鉄、蹄状態、ソエ、骨瘤、馬状態、バンテージ |

## 2. 利用上の整理ルール

- 原本のコード値を変更・再採番しない。
- 「スペース＝データ無し」等の原本注記もコードの一部として扱う。
- 同じ数値でもコード体系が異なれば意味は異なるため、必ずコード表の種類とセットで解釈する。
- 固定長仕様中の「コード表参照」は、本資料の該当章へ対応させる。
- 特記コード・脚元コードなど大量のコードを持つ表も、省略せず原文を保持する。
