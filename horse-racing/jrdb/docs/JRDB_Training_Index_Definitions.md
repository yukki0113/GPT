# JRDB 調教関連指標 定義メモ

## 位置づけ

JRDBの調教関連項目について、中央競馬予想プロジェクト内で参照するための定義メモ。

この文書は、ユーザーがJRDBの「調教に関するページ」から転記した説明を整理したもの。固定長データ定義だけでは読み取りにくい各指標の意味を補完するために保持する。

- 原文の意味を勝手に補完せず、確認できた範囲だけを記載する。
- 実装時は固定長仕様・コード表・実データと突合し、フィールド対応を確認する。
- この文書の「プロジェクトでの扱い」は、元説明そのものではなく中央競馬予想プロジェクト側の設計方針。

---

## 1. 調教指数

### 元説明の要点

東西の各専門情報紙の予想・評論家等について、担当調教コースでどれだけ正確に馬の状態を判断できているかをデータベース化し、それを元に各専門情報紙の印を分析して算出した数値。

数値右側の矢印は、調教から見た馬の調子を5段階で示す。

| 矢印 | 意味 |
|---|---|
| ↑ | デキ抜群 |
| ／（右斜上） | 上昇 |
| → | 平行線 |
| ＼（右斜下） | やや下降気味 |
| ↓ | デキ落ち |

例として「調教 -10 ／」のように、指数がマイナスでも矢印が上昇を示す場合がある。

これは、

- 矢印: 専門情報紙の総合的な評価で構成
- 数値: 特定の予想・評論家の判断を数値化

という生成元の違いによる。

元説明では、各馬の状態を判断する際は数値より矢印を優先する旨が示されている。

### プロジェクトでの扱い

`調教指数` は調教時計そのものの指数ではなく、専門紙・評論家の評価を統計加工した **Human/JRDB Judgment signal** として扱う。

- 独自調教時計モデルの基礎素材とは分離する。
- `調教矢印` も同じく判断系シグナルとして保持する。
- Ability/Edgeへ無条件に採用せず、独自Workout特徴量を入れた後でも追加予測力があるかをwalk-forwardで検証する。
- 特に `ActualRunPerf - AbilityPrediction` との関係を見て、Edge追加情報として有効か検証する。

## 2. 追切指数

### 元説明の要点

調教タイムを比較するための指標として算出され、可能な限り標準化されている。

基準は **「条件クラス馬の一杯追い切り」を60**。

主な補正:

#### 馬場差補正

調教コース・調教日ごとの調教タイムのばらつきを補正する。

#### 乗り役補正

騎手騎乗時は助手騎乗時より速いタイムが出るなど、乗り役による時計価値の違いを考慮し、騎手・助手・調教師で分類して補正する。

助手個々の体重差まではデータがないため考慮されない。

### 表示形式

「追い切り」は、

`コース + 強さ + 追切指数`

で表現される。

例:

`CWⅰ60`

- CWコース
- 馬ナリ
- 追切指数60

強さ表現:

- ⅰ: 馬ナリ
- ⅱ: 強目
- ⅲ: 一杯

また、特にレース直前週の水曜または木曜の強い追切を「本追切」とする。

### プロジェクトでの扱い

`追切指数` は完成予想ではなく、調教時計を比較可能にするための **preprocessed / standardized workout feature** として扱う。

独自Raw時計標準化と並列に比較する。

1. CHA Raw時計から独自標準化したWorkout特徴量
2. JRDB追切指数
3. 両者併用

を比較し、未知年での予測性能を検証する。

JRDB追切指数には、独自再現が難しい乗り役補正等が含まれるため、Raw素材と同等に有力な基礎特徴量候補とする。ただしJRDB独自の補正処理であることはprovenanceとして保持する。

## 3. 仕上指数

### 元説明の要点

馬の仕上状態を表す指数。

既に前走時点で仕上がっている場合は、状態を整えるだけで特に強い追切を行わないことがある。

- 調教量が少ない、または弱い調教が続く → 仕上指数は下がる
- 強い調教を行う → 仕上指数は上がる

基準は **「条件クラス馬の力を出せる状態」を60**。

「仕上がり」は、

`仕上指数 + 調教量変化 + 仕上指数変化`

で表される。

例:

`60A++`

- 仕上指数60
- 調教量は充分
- 仕上指数はプラス変化

### プロジェクトでの扱い

`仕上指数` は単なる追切時計ではなく、中間の調整過程を含めた **Preparation State / JRDB加工判断** として扱う。

重要な点は、追切指数と仕上指数を同一概念として扱わないこと。

例えば、

- 追切指数が低いが仕上指数が高い
- 追切指数が高いが仕上指数が低い

という乖離自体を特徴量候補とする。

候補:

`workout_finish_gap = 追切指数 - 仕上指数`

ただし符号の良し悪しは事前に決めず、バックテストで評価する。

## 4. 調教量変化

### 元説明の要点

ローテーション、馬体（良・余裕等）別に必要な調教量を「標準攻め量」として設定し、

- 時計になった本数
- 調教の強さ（一杯・強目等）

を元に評価する。

仕上がっていない馬の標準的な攻め量は、レース後1週休んでから、強目以上を週1本とする考え方が示されている。

評価:

| コード | 意味 |
|---|---|
| A | 多い |
| B | 普通 |
| C | 少ない |
| D | 非常に少ない |

### プロジェクトでの扱い

Aを単純加点、Dを単純減点とはしない。

調教量の意味は、休養日数・ローテーション・キャリア・前走時の仕上状態等と相互作用すると考え、Edge候補として検証する。

例:

- 長期休養明け × D
- 短期ローテ × C/D
- 新馬 × A
- 既に高仕上状態 × B/C

などを別条件で評価する。

## 5. 調教パターン / 調教タイプ

### 元説明の要点

調教過程を、**調教量 × 調教強度** の組合せで分類する。

概念表:

| 調教量 / 強さ | 軽い | 中間 | 強い |
|---|---|---|---|
| 多い | 乗込 | 標準多め | スパルタ |
| 中間 | 馬ナリ平均 | 標準域 | 一杯平均 |
| 少ない | 軽目 | 標準少め | 急仕上げ |

※ 元ページの表は配置表現を含むため、上表はその意味を整理したもの。固定長コード値との対応は別途コード表・実データで確認する。

### プロジェクトでの扱い

`調教タイプ` は「今回までどういう調整過程を踏んだか」を表す Preparation Pattern として扱う。

- 新馬Abilityでは絶対的な調整過程そのものを説明変数候補にする。
- 既走馬Edgeでは前走時の調教タイプから今回への遷移も候補とする。
- 「スパルタが良い」「軽目が悪い」のような固定評価は行わない。

候補:

- `current_training_type`
- `previous_training_type`
- `training_type_transition`

---

## 6. 調教コース種別

### 元説明の要点

中間調教過程で主に使用した調教コースを示す。

1. 坂路調教
2. コース調教
3. 併用（坂路・コース併用）

一般論として、

- 坂路調教: スピード重視
- コース調教: スタミナ強化

と説明されている。

### プロジェクトでの扱い

「坂路だから短距離向き」のような固定加点にはしない。

- 新馬Abilityの調教パターン特徴量
- 既走馬Edgeの自己比/前走比変化
- 距離・surface・休養日数等との交互作用

をバックテストで検証する。

一般論部分は説明として保持するが、指数ロジックには検証なしで採用しない。

## 7. 調教データのレイヤー分類

中央競馬予想プロジェクトでは、調教項目を以下のように分離する。

| Layer | 主な項目 | 扱い |
|---|---|---|
| T-Raw | CHA調教時計、コース、ハロン、追切強度、併せ情報等 | 独自特徴量の中心 |
| T-Prepared | JRDB追切指数 | 標準化済み素材として独自Rawと比較・併用 |
| T-Preparation | 仕上指数、調教量変化、調教タイプ、調教コース種別 | 仕上状態・調整過程の特徴量候補 |
| T-Human/Judgment | 調教指数、調教矢印等 | JRDB/専門紙判断信号。独自特徴量への追加価値を検証 |

この分類により、JRDBのデータは積極的に利用する一方、JRDBの判断を独自指数へ無条件に取り込まない。

## 8. Ability / Edge への基本配分

### 新馬・低キャリア馬

自己履歴が少ないため、調教の絶対水準をAbility情報として強く利用する。

候補:

- 追切指数絶対値
- 独自Workout標準化値
- 仕上指数
- 調教量変化
- 調教タイプ
- 調教コース種別
- 併せ馬情報

血統Prior等と合わせて `DebutAbility` を構成する。

### 既走馬

絶対調教水準より、自己通常値・前走時からの変化をEdgeとして重視する。

候補:

- `current_workout - horse_workout_baseline`
- `current_workout - previous_workout`
- `current_finish_index - historical_finish_index`
- `training_type_transition`
- `finish_index_delta`
- `training_volume_change`

---

## 9. 検証順序

調教の追加価値は以下の順で段階的に評価する。

1. 調教なし
2. CHA Raw時計由来の独自Workout
3. JRDB追切指数のみ
4. 独自Workout + JRDB追切指数
5. + 仕上指数
6. + 調教量変化
7. + 調教タイプ / 調教コース種別
8. + 調教矢印
9. + 調教指数

既走馬では `ActualRunPerf - AbilityPrediction` の予測改善、新馬では `DebutRunPerf` の予測改善を主に見る。

特に以下を重点比較する。

- 独自Raw標準化 vs JRDB追切指数
- 追切指数まで入れた後の調教矢印の追加価値
- 新馬 / 低キャリア / 長期休養明け / 通常ローテ別の効果差

---

## 10. 設計上の仮説

現時点の検証仮説:

> 調教の絶対水準が最も効くのは、新馬・低キャリア馬・長期休養明け。通常ローテの既走馬では、絶対水準より自己比の変化が重要。

この仮説は結論ではない。2010〜2025の時系列バックテストで検証し、未知年で追加価値が確認できた範囲だけを採用する。
