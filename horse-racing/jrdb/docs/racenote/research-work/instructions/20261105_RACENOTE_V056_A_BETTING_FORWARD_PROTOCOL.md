# RaceNote v0.5.6 — 自信度Aの購入／見送り研究 前方検証プロトコル v0.1
制定: 2026-11-05 / Status: **PRE-REGISTERED SHADOW RESEARCH / NOT PRODUCTION BETTING**

## 目的
Confidence A（◎が勝ち切ると積極的に支持できる）と、投資価値のある馬券を混同しない。Aの予測精度を保ちながら、購入／見送りと購入券種の正の期待値を独立に検証する。A/B/C/Z定義、5頭選別、Challenger、印、Xに掲載する予想、Prediction/Confidence Freezeを変更しない。

既存の20日・645R研究でA121Rの単勝回収率66.9%、第2期のA複勝86.2%、◎軸馬連4点68.0%、◎軸3連複6点76.6%、BOX拡張部分は大幅マイナス。確定最終単勝オッズによる閾値最適化は不採用。

## 前方検証で厳守する順序

1. **Prediction**：通常の全頭比較→ordinary five→◎○→Challenger→最終印→Prediction Freezeを完了。結果・払戻・当日市場は未参照。
2. **Confidence**：凍結◎について正式A/B/C/Zを独立LLM著述。◎の直接の勝ち筋、他勝利候補との差、主要敗因、不確実性をレース固有の根拠で説明。B/Cは勝利序列の確信度。Confidence Freeze・保存SHA・結果未閲覧確認を完了。
3. **研究用事前評価（オッズ非参照）**：Aのみ、`winning_case`の直接性、主要相手との比較、主な敗因を確認する。勝率数値モデルが正式に校正されていない間は`p_win=null`、`calibration_status=NOT_VALIDATED`とし、もっともらしい確率を捏造しない。将来確率推定を導入する場合はモデル・特徴量・校正標本・版・算出時刻をGitで事前固定し、当日価格閲覧前にその評価値を再Freezeする。
4. **価格スナップショット（両Freeze後）**：対象レースの決めた時点（例：発走予定10分前）で、その時点に実際に表示された◎単勝・複勝等オッズを記録し、`snapshot_at`、レースキー、取得元、馬番、対象券種、取得成否を不変保存。確定最終オッズで「買える時点の価格」を代用しない。欠測は`MISSING_MARKET`として隔離し、見たことにしない。
5. **Shadow Ticket Decision**：仮想馬券の`BUY`／`SKIP`、予定単価・点数、参照した事前評価版・価格スナップショットを結果閲覧前に固定。**このv0.1では自動購入しない。**
6. **結果解禁後**：JRDB SED/HJCのResult Queryで実払戻・出走取消／返還・的中・支出を検証し、レースキー・不変SHAで結合。結果後にラベル・価格・購入可否を変更しない。

## 研究上の比較戦術
全券種、各点100円とし、同じA候補群について次を記録する。

| 戦術ID | 定義 | 位置づけ |
|---|---|---|
| A-WIN-ALL | Aの◎単勝1点をすべて購入 | 一律購入ベンチマーク |
| A-PLACE-ALL | Aの◎複勝1点をすべて購入（頭数・払戻条件を正規処理） | 安定性検証ベンチマーク |
| A-QUIN4 | Aの◎から残る4印へ馬連4点 | 相手形成ベンチマーク |
| A-TRIO6 | Aの◎＋他4印から3連複6点 | 相手形成ベンチマーク |
| A-SKIP-ALL | Aも買わない | 支出ゼロの基準線 |
| A-VALUE-SHADOW | 事前に校正済みの勝率推定×実際の購入可能オッズに十分な余裕がある場合だけ◎単勝1点、ほかは見送り | **校正モデルが正式に揃うまで実行不可** |

A-VALUE-SHADOWの固定候補基準は、校正済み`p_win`と表示単勝倍率`o`を用いた `p_win * o >= 1.10`、または校正不確実性の下限での `p_win_lower * o >= 1.00` を必要条件とする案。ただし、**この数値は後方利益の証明ではなく次段階で精査する研究仮説**。校正状態が`NOT_VALIDATED`ならすべて`NO_EDGE_ESTIMATE`で取引不可。オッズと勝率の相関を無視して「Aは一律勝率30.6%」と代入することは禁止。

## この研究で採用しないもの
- Aを自動購入と解釈すること。
- 結果確認後に「勝った馬だけが高倍率だった」などの閾値を採用すること。
- Shadow v2.2の3着内軸B/Cを勝ち馬確信度に逆輸入すること。
- 第1期の3連複98.8%だけを根拠に券種を選ぶこと。
- Aで馬連・3連複を機械的に5頭BOXへ広げること（20日通算の追加回収率はそれぞれ43.3%、22.9%）。
- 市場閲覧後に予想のConfidenceや◎○▲△△を変更すること。
- 欠測や除外された馬を0払戻の通常不的中として処理すること。実際の払戻・返還を正規確認する。

## 監査と評価
- 最低でも**新規20BTDAY程度を目安**とし、各日のA件数を見てA100R以上を確保することを推奨。件数を達成するためAを増量しない。
- Aの◎勝率・3着内率、勝率区間（単純な二項区間と開催日ごとの感度）、市場人気分布、実際の購入可能価格、購入率、的中率、単勝／複勝／馬連／3連複の投資・払戻・収支・ROI、最大連敗数、最大日次損失と月次損失を併記。
- 未購入レースの◎勝敗も必ず保持し、見送りによる機会損失を検証する。
- 高配当1レース依存を明記し、恣意的な高配当の除外はしない。
- 最終回収率1点だけでなく、期間分割・開催差・市場価格データの欠測率・確率校正を確認する。新戦術を評価する前に採否基準と比較対象を固定する。
