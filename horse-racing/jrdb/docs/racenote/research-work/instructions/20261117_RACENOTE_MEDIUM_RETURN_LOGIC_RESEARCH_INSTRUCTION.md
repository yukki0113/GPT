# RaceNote 研究テーマ — 中配当レンジを再現性ある根拠で狙う馬券ロジック

Date: 2026-11-17  
Status: **ACTIVE RESEARCH THEME / DESIGN BEFORE NEW LOGIC**

## 1. 研究目的

RaceNote の最終目的は、予想文章や評価項目を詳細化すること自体ではなく、**馬券で継続的にプラス収支を目指すこと**である。

そのため、本研究では次の両極を避ける。

- 低配当の「簡単なレース」を高頻度で当てることだけを目標にする。
  - 一度の不的中で、それまでの小さな利益が大きく失われやすい。
- 大穴・極端な高配当だけを狙い続ける。
  - 資金・メンタル両面のドローダウンが大きく、再現性ある運用になりにくい。

狙うのはその中間である。

> **数敗分を回収できる中配当レンジの馬券を、偶然ではなく、事前に説明可能なロジックでそこそこ継続的に的中させる。**

1勝3敗でも、その1勝の払戻によって4R合計の回収率が100%を超えるなら、その区間は利益である。
したがって「最大払戻を除いたら負け」という反実仮想だけで戦略を否定しない。

重要なのは、当該高払戻が**たまたま当たったものか、ロジックが事前に狙って取ったものか**を分けることである。

## 2. 現在の出発点

BTDAY-0192〜0197の180R再分析では、v0.5.6の印5頭に以下の特徴が確認された。

- 3着以内馬を2頭以上捕捉: 138/180R = 76.7%
- 3着以内馬3頭を全捕捉: 50/180R = 27.8%
- ◎3着以内: 106/180R = 58.9%
- ◎着外でも、印内の他馬2頭以上が3着以内: 46/180R

このため、v0.5.6は「5頭の中に馬券候補を複数含める」能力を持つ可能性がある一方、次は未解決である。

- どの2頭・3頭の組み合わせを買うべきか。
- どのレースを購入対象にするべきか。
- 的中しても低配当すぎる買い目をどう避けるか。
- 中配当を狙える状態を事前情報だけで識別できるか。

## 3. 研究仮説

主仮説:

> v0.5.6 の既存Prediction / Reader / Confidenceに含まれる情報から、単純な印順固定よりも、中配当レンジの馬券成立を事前に識別する特徴・比較規則を抽出できる可能性がある。

ただし、「選べないのは情報が足りないから」と最初から仮定しない。

以下を区別して検証する。

1. 既存情報で十分だが、比較方法が悪い。
2. 情報を増やしてもレース不確実性を十分に減らせない。
3. 的中ペアを識別できても、市場価格に妙味がない。
4. 現行情報には市場を上回る優位性がない。

新しい情報やReader項目を追加するのは、既存情報だけでは説明できない不足が具体的に確認された後とする。

## 4. 研究上の評価軸

単純な的中率、単純な総回収率だけでは評価しない。

最低限、以下を併記する。

- 総投資額
- 総払戻額
- 総回収率
- 的中R数 / 的中率
- 的中時平均回収倍率
- 1的中が平均何敗分を回収しているか
- 払戻倍率レンジ別の的中数
- 最大連敗
- 最大ドローダウン
- 収益の払戻集中度
- 中配当レンジを事前ロジックどおりに取れた件数
- 高配当的中が事前ルールの対象だったか、偶発的な拾いだったか

「最大払戻を除いた回収率」は、収益集中度を見る補助指標としては使用してよいが、**それ単独を戦略否定の主判定にしない**。

## 5. 中配当レンジ

現段階では固定の倍率境界を正本化しない。

初期分析では、例えば以下のような複数レンジで分布を確認する。

- 投資額未満
- 1.0〜1.99倍
- 2.0〜3.99倍
- 4.0〜7.99倍
- 8.0倍以上

これは探索用の区切りであり、結果に合わせて最適な閾値を後付けして成果化してはならない。

研究目的は、**数敗分をまとめて回収できる倍率帯を、十分な頻度で事前に狙える条件が存在するか**を確認すること。

## 6. 180Rで行う探索分析

BTDAY-0192〜0197の180Rは、すでに結果既知の設計用標本として使用する。

ここでは性能証明を行わず、次の仮説候補を発見する。

- ◎○、◎▲、○▲、◎△、○△等の印位置別ペア
- Confidence A/B/C/Z
- ◎と○、○と▲などの相対評価差
- Reader上の能力・距離・脚質・展開材料
- 印5頭内の序列集中 / 混戦度
- 印外脅威
- 同時好走しやすい / 競合しやすい脚質構造
- 券種別に成立した中配当の条件
- 的中したが低配当だったケースとの対照

重要なのは、結果確認後に「○▲が高かったから○▲を買う」のような単純な後付けルールを作らないこと。

各候補は、
- なぜ事前に識別できるのか
- どのReader証拠を使うのか
- どの逆条件では見送るのか
を明示する。

## 7. 次段階の検証設計

180Rから仮説候補を抽出した後、未使用の結果未照会BTDAYで clean-blind 検証する。

最低限、以下を事前Freezeする。

- 対象レース
- 券種
- 買い目
- 1点金額
- レース上限
- 日次上限
- 選定理由
- 見送り理由
- 結果未参照
- 市場情報を使う場合は、その時点と取得源

結果確認後に最も成績の良かった方式だけを選んで「成功」としてはならない。

固定ベースラインも併記する。

例:
- ワイド上位3頭BOX
- ワイド◎流し
- 馬連上位3頭BOX
- 3連複◎流し
- 3連複5頭BOX

## 8. P2との関係

P2 v0.1は破棄しない。

P2で確認できた重要な知見:
- 全頭評価を追加しても、買い目選択が自動的に改善するわけではない。
- BTDAY-0197ではBET対象12R中11Rで印5頭が3着以内馬を2頭以上捕捉した一方、実際のP2は16点すべて◎軸ワイドに偏った。
- 「より詳細な予想を作ること」と「収益性のある馬券を選ぶこと」は別問題。

したがって、P2をさらに複雑化する前に、本研究で**中配当を狙うために本当に必要な判断要素**を特定する。

## 9. 禁止事項

- 的中率だけを最大化する。
- 大穴的中だけを成功条件にする。
- 高配当的中を機械的に除外して戦略を否定する。
- 逆に、偶発的な高配当1件だけで戦略を成功認定する。
- 結果を見た後で対象レース・券種・閾値を都合よく変更し、事前成績として扱う。
- 結果既知180Rを新ロジックのclean-blind性能証明として再利用する。
- 根拠なくReader情報を追加し、予想詳細化そのものを改善とみなす。
- Confidenceを、勝ち切り自信度から無断で馬券期待値スコアへ読み替える。

## 10. 成功の考え方

研究のゴールは「毎回当たるロジック」ではない。

成功候補とは、未使用サンプルで、

- 数敗を許容しつつ、
- 中配当レンジを複数回、
- 事前に説明可能な同一ロジックで狙い、
- 総回収率・ドローダウン・再現性のバランスが改善する

状態である。

1勝3敗でも収支がプラスなら有効な区間になり得る。
その1勝を「無かったこと」にするのではなく、**その1勝をなぜ事前に狙えたのか**を監査する。

逆に、同じ条件で中配当を繰り返し狙えない場合は、ロジックを増築し続けず、仮説を棄却または保留する。

## 11. 次の具体的タスク

次の研究作業は、180Rについて以下を行う。

1. 実際の的中馬券を払戻倍率レンジ別に再分類する。
2. 中配当レンジの的中を、印位置・Confidence・Reader特徴・脚質構造等で説明できるか探索する。
3. 低配当的中・不的中・極端な高配当的中を対照群として比較する。
4. clean-blindで検証可能な少数の候補ロジックへ絞る。
5. 新しいBTDAYで事前Freezeして検証する。

新規のRaceNote/P2実装は、この探索結果から具体的に必要性が示されるまで開始しない。
