- 勝ち馬が印5頭内: 112/156R (71.79%)。
- 3着内馬2頭以上を捕捉: 118/156R (75.64%)。
- 3着内馬3頭すべて捕捉: 44/156R (28.21%)。
- 3着内馬捕捉件数の分布: 0頭=5R、1頭=33R、2頭=74R、3頭=44R。

## 4. P2: 組み合わせ評価の設計（案、未実装）

設計原則: ◎○▲△△を変更しない。Reader・凍結Predictionのみで「5頭の役割と印外の脅威」を再点検する。旧Confidenceと結果・払戻は事前判断に投入しない。**購入対象と券種と購入価格を別の工程**にする。

### Gate 1: 5頭外リスクと捕捉構造（購入対象の選別）
- レース条件とReader内の全出走馬を再点検する。上位5頭だけでなく、**印外で3着内に入る具体的な経路**を特定する。
- 印外の脅威を「有力」「不確実」「見落とし懸念」に分類し、その根拠（能力、同条件実績、展開、距離変更、新馬/障害の情報不足）をReaderの記録に紐付ける。
- 3着内馬3頭を印内に捕捉できる根拠が乏しい場合、3連複を積極選択しない。印外脅威が強ければPASSも許容。
- 単に頭数やレース種別だけで固定一律PASSとせず、各レース固有の理由を要求する。

### Gate 2: 印内の同時好走・馬券構造
- 5頭それぞれの「勝利経路／連対経路／3着経路／負け筋」、脚質、コース・距離・状態の裏付けを同じ表で比較する。
- 相手4頭を印順だけで `WIN_OR_TOP2` などに自動割当しない。実際のReader根拠と逆展開での順位変動を明示。
- **WIDE適性**: 2頭の着内が同じ展開で成立し得るか。候補ペアごとに同時好走経路を確認。
- **馬連適性**: 2頭の連対経路が同時成立するか。
- **3連複適性**: 5頭から3頭の同時着内経路が現実的か。単なる「5頭に有力馬が多い」では不足。
- ◎を軸にする根拠と、◎を含まない組み合わせの根拠は分ける。
- 同時好走可能性は独立勝率の単純積で計算しない（共通展開要因がある）。

### Gate 3: 券種と購入価格
- `PASS`、`WIDE_2_TO_4`、`QUINELLA_2_TO_4`、`TRIO_AXIS_3_TO_6`、`TRIO_BOX5_10` などを候補とする。ただし**具体的なペア/三頭組を事前に根拠付きで生成**し、一定点数へ埋めるための架空の相手を増やさない。
- 初期段階は市場オッズを使わない「的中構造」検証を別指標で記録する。**実際のBET価値判断には事前オッズによる採算条件が必要**である。オッズがないと積極的なプラス期待値を宣言できない。
- 各レース上限額、日次上限、1券種当たり予算を事前設定する。1点100円基準で比較。

## 5. 開発・検証の順序と禁止事項

1. 156RをP1開発用標本に固定。外れた原因の実態（印外1頭、軸外、低配当）を、決済原票とReader双方で詳査する。失敗レースを2〜3Rだけ選ぶ際は成功例と対照にする。
2. P2 Gate1/Gate2をReaderの**結果を見せない別判断枠**で実装。旧Confidenceは入力しない。P1と同じ156Rで説明例を作る場合は必ず「結果既知・設計用」とラベル付け。
3. 新規結果未照会の開催日で「購入レース・買い目・条件・上限額」を結果照会前にFreeze。
4. Freeze後に正規SED/HJCで決済。必ずWIDE・馬連・3連複の事前固定ベースラインを併記。
5. 評価は的中R、回収率、損益、投資額、払戻集中（最大1件除外）、開催日別、購入対象と見送り対象の捕捉率で行う。
6. 新ロジックが「絶対勝てる」「安定してプラスになる」と結論づけることを禁じる。2周目再利用標本・後知恵の複数比較を明示。

## 6. 暫定結論

**最大の改善課題は「◎軸固定」単独でなく、3着内馬3頭を5頭に揃える必要のある3連複に過度依存したことと、印外脅威の把握不足。** 結果的に2頭捕捉の多数レースを的中へ転換できていない。ただしWIDEでも一律BOX購入は負けており、券種変更だけで収益化はできない。次は「印外3着内リスク」「2頭/3頭の同時好走」「購入価格」を別々に評価する。
