## 1. 検証方法と母数
Google Drive既存のannual Rawフォルダから2021〜2025年の `BAC_YYYY.zip`、`KYI_YYYY.zip`、`SED_YYYY.zip` （計15ZIP）を取得。各ZIPのcanonical memberの固定長・キーを検査し、GitHub `horse-racing/jrdb/src/jrdb_raw.py` の**現行1-based byte offset**に合わせた一時的な監査用投影で照合した。恒久的なRaw parserは作っていない。会話上の2026-11-15 PACI/SED実査も別の既存証跡とする。
- 今回の3年対5年比較は、**完了済み暦年**の `2023-01-01〜2025-12-31` と `2021-01-01〜2025-12-31` であり、2026-11-18を起点とした厳密なrolling 3/5年ではない。2026年YTD全量は未追加。
- 年次Rawは「当時の事前公開スナップショット」を証明しない。再現検証のため、入力配信時刻・当日直前騎手変更のFreezeを別途担保する。
- 当初予定したWarehouse Parquetへの直接DuckDB集計は、このランタイムのduckdb/pyarrow未導入かつpip DNS failureのため実施せず、一次Raw現物で再現した。Warehouseの受入状態と本実査の範囲を混同しない。

## 4. 前走騎手・乗替り
KYIの `first_prev` は `blood_registration_no + date` のSED結果キーへ結合。2021〜2025で前走結果を実際に読み出せた各件について、**前走の結果日が対象日より前**かつ馬ID一致であった。2025年のBAC欠損対象は事後監査専用にSEDの同日レース日を補助使用して時系列整合だけ確認した。SEDを対象レースの事前予想へ渡すことは一切許さない。

大多数の未解決はJRA年間SEDに含まれない地方・海外等の場コードに関連する。国外・地方騎乗履歴をJRA実績に混入させない。2010〜2020の全履歴をJPDBへ複製する必要性はこの結果からはないが、3/5年の先頭年で「窓の外の前走」を欠損と区別すること。継続・乗替り・初騎乗・主戦ラベルは定義未確定。

## 5. SED異常区分の母数
JRDB公式 `Sed__sedsiyo_doc`（Drive `official_specs_20261015`）では、異常区分 `0=異常なし`, `1=取消`, `2=除外`, `3=中止`, `4=失格` と説明されている。

5年SED実測: `0=235,838`、`1=366`、`2=496`、`3=1,076`、`4=0`、**`5=2`（現行確認済み公式表に定義なし）**。
- `0`の正常完走を勝率・複勝率の主要な着順母数候補とする。
- `1/2`を「出走した騎乗」と数えることは避ける。分母定義は取消時点・レース種類等を含めP1前にfreeze。
- `3/4`は出走事実と着順評価を区別する。
- `5`は未定義のためその2件を自動で正常扱いせず `UNKNOWN / REVIEW_REQUIRED`。
- 全コード原文を保存し、統計母数を変えるときは `population_filter_id`を変更する。

## 6. Course Profile実結合
既存RRDB Course Fitの受入済み2026-01-01 snapshot `RRDB_Horse_Course_Fit_v0_1_asof20260101_g38370479179_part1.zip` からPhase3の `course_master_seed_v0_1.jsonl` **177行**、`course_jrdb_mapping_seed_v0_1.jsonl` **433行**、`course_geometry_configuration_v0_1.jsonl` **57行**を直接検査。使用ZIP SHA-256: `b27f2293a100755aa1ac0c902c2e6338a8393cd208c5de0912ff7a81f89783ba`。

BACの平地16,600レースについて
- JRDB実観測タプル→mapping発見 **16,600/16,600**。いずれも `mapping_status=CONFIRMED`。
- mapping→`course_key`→master結合 **16,600/16,600**。
- geometry identityキーは **16,600/16,600**。
- **物理属性の適用可能epoch** は `physical_valid_from=2023-01-01`。2023〜2025のBAC平地 **9,940件はepoch適合**、2021〜2022 **6,660件は非適合**。マスタの `physical_data_status=PARTIAL` であり、適合と物理属性が全面的に確定済みという意味は異なる。
- 2025年 `BAC_2025.zip` は `KYI_2025.zip` / `SED_2025.zip` に存在する **53レース・735頭を欠く**。欠損は `KYI251213.txt` 374頭、`KYI251214.txt` 361頭。よって上記100%結合は**BACが存在する平地レースだけ**を分母とする。
- 欠落した53レースを**開催後SEDから研究用に復元した観測値**で既存mappingに照合すると、51レースが `CONFIRMED`、2レースが `PROVISIONAL`。これは事後研究の補助事実であり、歴史的開催前BACの存在を証明しない。RaceNote replayへSEDを事前入力として流用しない。

**帰結**: 3年の物理コース特徴は2023年以降の限定的な検証済みepochで実行できる見込み。5年窓へ拡大しても2021〜2022の物理坂・直線長等を現在値で埋めてはいけない（物理要素を除くコース分類のみ可、または正式な過去versionが必要）。
