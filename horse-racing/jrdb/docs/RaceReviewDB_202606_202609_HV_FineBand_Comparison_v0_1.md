## 要約

- HV01・HV02とも、Q85–Q90の3着内率が6〜7月、8〜9月の両方で各signal内の最高値。Q80–Q85も6〜7月は8〜9月より高く、弱さが継続したとは言えない。
- Q90–Q95はHV01で6〜7月25.27%から8〜9月29.17%へ上昇。HV02も25.00%から26.67%と近い。HV02の両期値は比較的近い一方、ROIは少標本の払戻に左右される。
- Q95+は6〜7月にはHV01 29.09%、HV02 25.45%で、8〜9月（24.00%、18.84%）より高い。8〜9月の低下は確認できるが、6〜7月時点で明確に弱い帯ではなかった。
- Q85–Q90の再現性は見えるが、「Q85〜Q95全域」が一様に強いとは言えない。とくにHV01 Q90–Q95は6〜7月に相対的に低い。
- Q95+が各期でQ85–Q90を下回る点は、最上位帯が必ず最も強いという前提への反証材料。ただし、2期間・限定標本の結果であり、閾値変更を決める証拠ではない。

## 方法・対象

6〜7月は既存SEDとRRDB `fact_horse_performance` を使って集計し、Raw全履歴の再構築は行っていない。sourceは対象馬の直近有効な過去flat走（target_dateより前）、`performance_signal = -horse_adjusted_delta_per_1000m`。targetは出走済み・平地（surface code 1/2）でsource特徴量が有効な行。対象は計16開催日、7,335 target entries（6月3,589、7月3,746）。signal該当数はHV01 497、HV02 260。

- HV01: source_finish >= 4 かつ performance_signal >= Q80
- HV02: source_finish >= 6 かつ performance_signal >= Q80
- 固定閾値: Q80 = -0.09305555555555287、Q85 = 0.03422932330827132、Q90 = 0.16777149321267684、Q95 = 0.3612475482
- Q85は比較可能性のため、既存8〜9月分析で固定した値をそのまま使用。今回の6〜7月データでは再計算していない。
- 各馬の単勝・複勝は各100円均等購入換算。ROI = 払戻合計 / 投資合計 × 100。

## 指示書の確認事項

### Q1: 6〜7月でQ85–Q90 / Q90–Q95はQ80–Q85を上回るか

両signalともQ85–Q90はQ80–Q85を上回った（HV01 31.30%対28.48%、HV02 29.87%対19.05%）。Q90–Q95はHV01で下回る（25.27%対28.48%）が、HV02では上回る（25.00%対19.05%）。したがって、Q85–Q90の優位は両signalで再現し、Q90–Q95はHV02のみ明確に上回った。

### Q2: Q95+は6〜7月でも相対的に弱いか

Q95+の3着内率はHV01 29.09%、HV02 25.45%。Q85–Q90より低い一方、Q90–Q95より高く、Q80–Q85に対してHV01はやや高く、HV02は高い。6〜7月のQ95+を一律に弱いとは評価できない。

### Q3: HV02のQ85〜Q95の再現性

Q85–Q90は両期間でQ80–Q85より高く、HV02で最も再現性の強い帯だった。Q90–Q95も両期間で25.00〜26.67%と近い3着内率で、Q80–Q85より高かった。市場面では複勝ROIが94.32%から102.00%で近いが、N=44/60のため安定収益の根拠とはしない。

### Q4: Q80–Q85は継続して弱いか

HV01は6〜7月28.48%から8〜9月20.87%へ低下。HV02は19.05%と18.49%でほぼ同水準。HV01では8〜9月だけ低かった可能性があり、HV02では両期間ともQ85–Q90より低い。いずれもQ80–Q85から3着内馬が出ており、「明確に弱い」と一般化はできない。

### Q5: Q90–Q95は安定しているか

HV01の3着内率は25.27%から29.17%、複勝ROIは72.31%から90.17%で、強さの程度は期間で動いた。HV02は3着内率25.00%から26.67%、複勝ROI94.32%から102.00%で近い値だった。したがってHV02の着順率は比較的安定して見えるが、ROIや少標本の再現性までは断定できない。

### Q6: Q95+が両期間でQ85〜Q95を下回る場合の解釈

Q95+は両signal・両期間でQ85–Q90を下回ったため、「最上位ほど必ず強い」という単調な前提を疑う材料にはなる。ただし6〜7月のQ95+はQ90–Q95を上回り、Q80–Q85も上回る組合せがあるため、「Q95+は常にQ85〜Q95全体より弱い」とまでは言えない。別期間・少数標本による反証材料であって正式なルール変更の根拠ではない。

## 結論と注意点

今回最も明瞭に期間をまたいで再現したのは、HV01/HV02ともQ85–Q90の高い次走3着内率。HV02ではQ90–Q95も2期間で近い成績だった。Q95+の評価は8〜9月に大きく低下したが、6〜7月には中位以上であり、期間依存性が残る。ROIはとくにNの小さいbandで払戻に左右されるため、順位づけや閾値選定には使用しない。Q80/Q85/Q90/Q95、recommendation contract、表示仕様は変更していない。
