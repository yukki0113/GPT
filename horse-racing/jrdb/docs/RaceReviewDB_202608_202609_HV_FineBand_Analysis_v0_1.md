## 要約

- HV01はQ85–Q90が3着内率29.71%で最上位。Q90–Q95も29.17%とほぼ同水準。
- HV02もQ85–Q90が28.57%で最上位、次いでQ90–Q95が26.67%。
- Q90–Q95は8月に両signalの最上位だった一方、9月はQ85–Q90を下回った。2か月を通じた一貫した弱さとは言えない。
- Q95+はQ85–Q90を両signal・両月とも下回った。今回の範囲では「最上位ほど強い」とはならなかった。
- Q80–Q85にも3着内馬が含まれ、Q80からQ90へ単純に切り上げると該当馬を落とす。今回の実績だけで閾値を変更する根拠にはしない。

## 方法と対象

既存のSEDおよびRRDB `fact_horse_performance` を利用し、Raw全履歴の再構築は行っていない。sourceは対象馬の直近有効な過去flat走（target_dateより前）とし、`performance_signal = -horse_adjusted_delta_per_1000m` を用いた。target側は出走済み・平地（surface code 1/2）で、source特徴量が有効な行。開催日が存在したのは計20日、target entryは7,914件（8月4,777、9月3,137）。分析対象のsignal該当馬はHV01 589件、HV02 325件。

- HV01: source_finish >= 4 かつ performance_signal >= Q80
- HV02: source_finish >= 6 かつ performance_signal >= Q80
- 閾値: Q80 = -0.09305555555555287、Q85 = 0.03422932330827132、Q90 = 0.16777149321267684、Q95 = 0.3612475482
- Q85は今回の対象期間の全target-entry keysからsource特徴量を引いた母集団（欠損除外、N=6,945）の線形補間85 percentile。着順・人気・オッズ・払戻を参照する前に一度算出し固定。
- 各馬の単勝・複勝は各100円の均等購入換算。ROI = 払戻合計 / 投資合計 × 100。

## 確認事項

### Q1–Q2: HV01/HV02で最も高い帯

両signalとも合算ではQ85–Q90が最も高い（HV01 29.71%、HV02 28.57%）。ただしHV01ではQ90–Q95との差は0.54ポイントで小さい。標本数もそれぞれ138/120（HV01）、77/60（HV02）であり、単月変動も踏まえて読む。

### Q3: Q90–Q95の弱さ

2か月合算でHV01はQ85–Q90とほぼ同じ、HV02はQ85–Q90を1.90ポイント下回る。月別では8月はQ90–Q95が両signalで最上位（32.53%、28.26%）、9月はQ85–Q90より低い（21.62%、21.43%）。よって当該期間に一貫して弱いとは言えず、月で方向が異なる。

### Q4: Q95+

合算の3着内率はHV01 24.00%、HV02 18.84%。Q85–Q90より低く、月別でもQ85–Q90を下回る。今回の2か月ではQ95+優位は確認できなかった。ただしNは125/69で、長期的な強さや安定性までは判断できない。

### Q5: Q80–Q85 / Q85–Q90の様子

Q85–Q90はQ80–Q85より合算でHV01 +8.84pt、HV02 +10.08pt。月別でもQ85–Q90の3着内率がQ80–Q85より高い。Q80–Q85もHV01 43頭、HV02 22頭が3着内に入っており、実績がゼロの帯ではない。

### Q6: Q80からQ90に絞る場合

Q80–Q90の範囲にはHV01で344件中84件、HV02で196件中44件の3着内があった。Q90以上にもHV01 245件中65件、HV02 129件中29件の3着内があった。Q80→Q90への切り上げはQ80–Q90の該当馬を対象外にするため、今回も有効馬を落とす結果になる。検出対象の絞り込みと見逃しのトレードオフがあり、今回の小標本だけから閾値変更を結論づけない。

## ROIの読み方・結論

ROIは2か月・少数件の払戻に大きく左右される。特に9月のHV02 Q90–Q95はN=14で単勝ROI 663.57%だが、安定収益の根拠にはならない。3着内率の順位とROIの順位も一致していない。今回の観察では、Q85–Q90の3着内率が両signalで高く、Q95+は相対的に弱かった。一方でQ90–Q95は8月に強く、Q80–Q85にも次走3着内が残っている。次段階では追加期間での再確認が適切であり、Q80/Q90/Q95の既存閾値や正式ルールは変更しない。
