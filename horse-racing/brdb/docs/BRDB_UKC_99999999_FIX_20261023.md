# BRDB UKC 99999999 日付選択修正（2026-10-23）

Status: BUILDER FIX COMMITTED / REBUILD VALIDATION RUNNING

## 原因
旧builder v0.1.0はUKCの`data_date`を8桁数字としてのみ検証し、文字列最大の観測を馬ごとの正本に採用していた。1999年アーカイブ中の8件（`UKC999999.txt`）に`99999999`があり、正しい後年の日付より優先されてしまった。

## 変更
- `build_brdb_pedigree_generation.py` のbuilder versionを `0.2.0` とし、generation IDの入力にbuilder versionを含めた。旧generation `9ad752020bd5801b` と衝突しない。
- `99999999` を使用対象から隔離。監査には`horse_id`、archive、member、行番号、元の日付値を保存。
- 他の不正な暦日を明示的に拒否。正常な`YYYYMMDD`のみ最新日付の選択対象とする。
- 元ZIPの改変・削除は行わない。
- `test_brdb_ukc_date_sentinel.py`で隔離と正常最新選択、実在しない暦日の拒否を検証。
- 正本CURRENT `eeca93556584a5b8`、RaceNote、Newspaper、PWAへの変更は行わない。
