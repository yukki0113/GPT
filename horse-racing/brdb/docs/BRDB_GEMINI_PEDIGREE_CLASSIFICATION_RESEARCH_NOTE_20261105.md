## 0. この資料の役割

BRDBの本来のゴールは、**任意のレースについて、新馬を含む全出走馬の血統に関する事実・過去の条件別成績・解釈を根拠付きで返すこと**。

このメモは「どの切り口で血統を分類・分析できるか」という**検討候補**を保存するものであり、taxonomyの確定、適性スコアの承認、予測性能の立証、CURRENT/RaceNote/PWAへの統合を意味しない。

**三者を分離する。**
1. **FACT（血統事実）**: JRDBの確認済み父・母・母父・父系/母父系コード、根拠付きの祖先ID/経路。
2. **CLASSIFICATION PROPOSAL（分類案）**: 大小の父系グループ、日本/米国/欧州/豪州等の競馬文化・競走環境に基づくタイプ。採用には辞書・定義・出典・版・レビューが必要。
3. **APTITUDE HYPOTHESIS（適性仮説）**: 切れ味、早熟、ダート、道悪、坂、小回り、持続力等。**血統だけで自動的に確定しない**。条件別成績と比較対象、時系列検証を必要とする。

## 1. 父系（サイアーライン）の系統分類

入力資料が挙げた候補。父→父の父→…という**父系の遡及**を基本とし、正式な大系統/小系統の割当ては既存 `lineage_code_master_v0_1.csv` と確認済みの系譜事実を優先する。

| 入力資料で言及された父系・血脈 | 代表例・派生の例（資料の説明） | 適性に関する資料の説明（**仮説**） |
|---|---|---|
| サンデーサイレンス（SS）系 | ディープインパクト、ハーツクライ、ステイゴールド | 日本の軽い芝、瞬発力・切れ味 |
| ノーザンダンサー（ND）系 | サドラーズウェルズ、ストームキャット、ダンチヒ等、派生による違い | サドラーズウェルズ＝欧州的なパワー、ストームキャット＝米国的スピード、ダンチヒ＝短距離/マイル等 |
| ミスタープロスペクター系／キングマンボ | キングカメハメハ、ロードカナロア | スピード・早熟性、ダート/高速芝 |
| ロベルト系、ナスルーラ系等 | （資料に固有代表馬の記載なし） | 小回り、荒れ馬場、急坂、1800m/2200m等の非根幹距離 |

- **注**: 「系統上の親子関係」と「適性」の両方を同一視しない。上表の例・系統階層も辞書へ登録する前に既存公式データと照合する。
- 一つの大系統の中で枝ごとに特性が異なり得るため、大系統ラベルだけで個体の適性を決めない。
- 外部サービス（元資料ではnetkeiba、TARGET frontier JV、JRA-VAN）での表記例は**参照候補**であり、公式JRDBコードを置換する根拠ではない。

## 2. 競馬環境に基づく「日本型・米国型・欧州型・南半球型」

ユーザー資料の候補分類を保管する。これは**馬の国籍・出生国ではない**。血脈が培われた環境や主な競走実績に着目した分類案であり、現在のBRDBでは確定taxonomyではない。

| 提案タイプ | 入力資料が挙げた舞台・特徴（**検証前の仮説**） | 例示された系統・血脈 |
|---|---|---|
| 日本型 | 軽い芝、高速馬場、上がり3Fの瞬発力 | SS系、キングカメハメハ系 |
| 米国型 | 前半のスピード、ダート、急坂、持続力 | ストームキャット系、フォーティナイナー系、A.P.インディ系 |
| 欧州型 | 重い芝、洋芝、道悪、スタミナ、底力 | サドラーズウェルズ系、ハービンジャー、トニービン系 |
| 南半球型（豪州等） | 超短距離・高速スプリント、早熟性 | （資料に固有血脈の指定なし） |

- 元資料は「主戦場・G1実績の国」から日本/米国/欧州型を判別する案を示す。ただし、**少数のG1実績や単一の祖先の出身国から機械的に断定しない**。
- 複数の地域的ルーツを持つ血統は複数タグ・不確実性を許容する。確認不能なら `UNKNOWN`。
- JRDBの父系・母父系**公式コードは地域ラベルそのものではない**。地域分類は独立したreviewed taxonomyで管理する。

## 3. 個別血脈・母父・祖先経路・クロス

入力資料が指摘した個別血脈と傾向の候補。

| 血脈・配置の例 | 入力資料にある適性の着眼点（**仮説**） |
|---|---|
| 母父Halo | 機敏さ・小回り・瞬発力、中山/阪神や内枠 |
| 父または母父Storm Cat | 初速・早熟性、ダート/高速芝、母父の場合のスピード補強 |
| トニービンを持つ | 東京等の広いコース、長く脚を使う持続力、左回り |
| Danzig（ダンチヒ）を持つ | 1200〜1600m、道悪/洋芝、ピッチ走法 |

- **配置を必ず区別する**: `sire_id == X`（父そのもの）、`broodmare_sire_id == X`（母父そのもの）、父側/母側の任意祖先にX、特定のS/D経路（例: DDD）、母父**系**にX系、同一祖先の複数経路＝クロス、はそれぞれ別の検索条件。
- 「Xを持つ」の意味を曖昧にしたまま集計しない。祖先ID・経路・深度・観測範囲・provenanceを返す。
- 祖先グラフに欠損があれば「存在しない」とはせず、`UNKNOWN` とする。完全な5代分のcanonical ID解決は最初の全馬レビューの必須条件としない。
- 血脈の位置による相乗・補強という説明は**そのままニックスや予想加点のルールにしない**。配合別サンプルと時間順の評価が必要。

## 4. DBによる条件別傾向分析の候補

元資料が示した操作順序：**条件絞り込み → 集計軸の切替 → 成績・回収・標本規模の確認**。

### 4.1 レース条件

- 例: 阪神芝2000m、中山芝1600mの重/不良馬場、東京ダート1600m。
- 必要な条件軸: 日付、競馬場/コース、芝ダ、距離・距離帯、馬場状態、クラス等。必要に応じて内外回り、枠、開催時期も検証する。
- 条件変更: ダート→芝、芝→ダート、距離短縮/延長等を追加の分析候補とする。対象馬の前走情報は**対象日以前**のものだけ利用する。

### 4.2 集計の切り口

1. 父（種牡馬）別。
2. 母父（BMS）別。
3. 父系・母父系の大系統/小系統別。
4. 父×母父、父系×母父系の組合せ（ニックス**候補**）。
5. 祖先・経路・クロス条件別（利用可能なID/coverageに限定）。

### 4.3 評価指標と扱い

- 件数: **出走回数と一意馬数を分ける**。同じ馬が複数回走ったことを考慮し、集計期間・年度も表示する。
- 着順: 勝率、複勝率、必要に応じて連対率。取消・除外・中止・競走成立・同着の扱いを統一する。
- 比較: 同条件の基準集団との比較、区間推定、人気・クラス・時期等の偏り。
- 回収率: 単勝・複勝の回収率、人気やオッズに対する妙味。**確定払戻/オッズ時点を定義できた場合だけ算出**し、回収率の高さだけで予測力を確定しない。
- 元資料は「最低20〜30頭以上」をサンプル数の目安として提案。これは**ユーザー提供資料の例示値**であり、BRDBの正式な一律閾値にはしない。条件の希少性、走数と頭数の差、比較誤差を含めて決める。
- 条件を大量探索したときの偶然の好成績を抑えるため、探索期間と後続検証期間を分ける。

## 5. 「任意レースの全頭レビュー」への利用候補（**仕様未確定**）

対象レースの各馬に対して、同じインターフェースで次の内容を返す案を検討する。

1. **血統事実**: 父/母/母父、確認済み系統、確認済み祖先と未解決の範囲。
2. **条件別実績**: 父・母父・系統・配合に対応した歴史的出走数、勝率/複勝率、同条件の基準値との比較。
3. **適性の説明**: 芝ダ/距離/競馬場/馬場に関するプラス材料、懸念、不明点。ただし「SS系だから必ず切れる」等の決め打ちを禁ずる。
4. **評価品質**: サンプル数、期間、当時利用可能なプロフィール、系統分類の承認状態、祖先欠損、統計的不確実性。
5. **新馬向けの扱い**: 当該馬の自己実績がないことを明示し、父産駒/母父産駒/配合/確認できた近親実績などの利用可能な他馬の根拠と混同しない。

**この5項目は今後ユーザーと詰める候補**であり、採点規則・レビューの出力優先順位・閾値を確定するものではない。

## 6. 導入境界と次の確認

- 既存JRDBパーサー/公式系統マスター/BRDB Reader/結果マートを再利用し、別の公式系統解釈器を作らない。
- Gemini資料は分類・検索アイデアの**インプット**。正式な地域タイプ辞書・血脈特性辞書に採用する前に、各候補の具体的出典・適用範囲・バージョンを別途検証する。
- 血統の**事実**とその**適性仮説**を同一カラムや確定済みレビューとして保存しない。馬名あいまい一致で祖先や親IDを確定しない。
- 既存 `brdb-review-v0.1`、BRDB CURRENT、RaceNote、新聞、PWA、公開予想、マーク/勝率モデルは**今回変更しない**。
