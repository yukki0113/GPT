## 実験仕様

時系列分割（各foldで`train = 2016..(test year - 1)`、`test = test year`）は既存P1-6計画を踏襲。すべての特徴符号化とロジスティック回帰の係数推定をtrain内で行い、テスト年度の結果をfitに使わない。

- **研究用非血統ベースライン**：競馬場コード、芝ダ、距離200m帯、レースクラスコード、馬番、開催月。
- **追加血統モデル**：上記に`sire_line_code`、`broodmare_sire_line_code`を追加。
- 同じ`LogisticRegression`（L2 `C=1`、`liblinear`、`random_state=26041104`）、同じトレーニングとテスト馬を使用。
- `abnormal_code=0`正常完走、`1`競走中止を出走分母へ含め、`2〜5`は除外。勝馬ちょうど1頭・出走馬2頭以上のレースだけを採用。二者とも同じraceとhorse roster。
- 研究上の主評価：テスト馬ごとの二値勝利`log loss`。副評価：Brier。主指標は`challenger minus baseline`なので**負なら改善**。
- 大きな制約：ベースラインは**本研究のために遡及学習した簡易モデル**であり、既存RaceNoteや市場人気を再現するものではない。距離・クラス等の入力はレース前に判る条件との仮定に依存する。日単位の同着・取消／異常区分と欠損による選択に注意。

- 年度別の**開催日**の区間がゼロをまたぐのは2021・2022・2025。2023・2024はゼロ未満。

- 上表は各軸**別々のone-way cluster bootstrap**。年度5クラスターは特に少ない。同一馬が年度をまたぐ依存、複数層が同時に作用する構造、重なりのある訓練ウィンドウは完全に補正しておらず、標準的なmultiway bootstrapを実装した主張ではない。公的な有意差／ROI／実運用改善を宣言しない。
- `P1-5`の扱い：**観測した改善の方向に対する依存構造の感度監査PASS**、多重比較とmultiway依存・独立年度の最終検証HOLD。
