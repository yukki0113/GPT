- Status: **PACI/UKC DATA ACCESS PASS / HISTORY TREND & RANKING NOT YET EXECUTED**
- 検証日: 2026-11-05
- 研究目的: PACIから任意の1レースを受け取り、⑤全出走馬比較・①父の産駒の同コース/距離実績・②母父の芝ダ/距離傾向を、既存JRDB/BRDBを優先してどこまで返せるか確認する。
- 次段階: ③父系×母父系の組合せ・④兄姉/近親検索（この試験には含まない）。
- 本書は**8頭の血統適性の順位、勝率推定、予想印**を作成・公開したものではない。原本・個票のGitHub公開なし。

## 4. 父・母父の母数ばらつき（参考、**成績ではない**）

旧研究用generation v0.2付属の固定2026コホート`verification/cohort_horses.csv`（10,680頭）と`verification/cohort_entries.csv`（39,543登録）を使用。2026-10-25までの**出馬表登録**に限定し、父/母父の名前完全一致でまとめた。UKC父母の正式な親ID結合や、生年制御、実出走判定は本表では行っていない。

対象8頭の各父・母父を参照したところ：
- 父の既出走登録コホートにおける一意産駒数は **2〜231頭**、出走登録件数は **6〜738件**。
- 母父別の一意馬数は **1〜646頭**、出走登録件数は **5〜2,481件**。
- 東京での登録数は父別で0〜120件、母父別で0〜329件。**芝2000m成績ではない。**
- 対象8頭は父7種類、母父6種類（重複あり）。これらの件数を血統評価に読み替えたり、旧2026対象コホートが2016〜2025年の全産駒数であるかのように使わない。

**示唆**: 少母数の父・母父について、単純勝率をランキングやプラス評価に使ってはならない。条件別の比較対象、標本不足処理、共通の比較ルールが⑤には必須。

## 6. 必要な最短次工程

1. **①を8頭で実測**: 接続済みAnalysis/過去結果データをReader経由で再利用し、父別の東京・芝・2000m完全一致と距離帯を`as_of<2026-11-01`で集計。父名、産駒数/走数、勝率・複勝率、同条件全体の基準値、欠損を返し、実クエリ時間を測定する。
2. **②の横断比較を追加**: 同じ`broodmare_sire_name`について芝・ダを横断した条件別出走/成績と複数距離帯の比較を取り、芝ダ型・距離型の判定可否をサンプル数とともに返す。ターゲット条件のみのP2では不足。
3. **⑤の比較仕様**: ①②の証拠を同じ全馬に適用。条件一致度・比較基準・母数/不確実性・未知を分け、当初は `POSITIVE / NEGATIVE / INSUFFICIENT_EVIDENCE` 等の根拠付き相対レビュー案として検討。父と母父の重複を単純合算して単一勝率にしない。
4. ③配合と④近親はその後。別のモデル訓練、未来開催の監視、BRDB CURRENT/PWA/RaceNote本番変更は今回不要。
