# BRDB P1-3 — 時系列分離・多重比較・同一馬クラスタ監査（2026-11-04）

## 判定

**研究用の検証処理：ローカルPASS。未知期間への効果再現：確認できず（0件）。**

この分析は2016〜2025年の後日確定された静的血統を使った*retrospective*な統計監査です。出走時点で利用可能だった血統情報の証明がないため、**予測バックテスト／本番投入の受入ではありません**。

## 固定入力

- P0-2 GitHubコミット版で全量再生成した研究用 `brdb_result_mart.parquet`、481,627行。
- マートSHA-256: `8b41f4b7132bc268428133535cce9c4aff79ac5b7b4c0dca5a5cdd5c1df13b63`。
- DuckDB `1.1.3`、Python標準ライブラリによるBH補正・正規近似（SciPy不要）。
- P1-1で**全10年間を見て採用済みの1,935グループを候補選択に使わない**。学習期間から独立に全グループを抽出。
- `normal_finisher`のみを率の分母とし、実出走数とは区別。血統の状態は`STATIC_LATER_SELECTED_SNAPSHOT_NOT_ASOF_VERIFIED`。

## 時系列分割

| 段階 | 期間 | 固定手順 |
|---|---|---|
| 学習 | 2016–2020 | `n>=100`, 観測年 `>=3`, 同条件baseline正常完走 `n>=150` を満たすグループを抽出。勝率・3着内率の差について馬IDクラスタ分散で両側z検定。2指標を単一familyとしたBH補正 `q<=0.10`。 |
| 検証 | 2021–2022 | 学習で残った仮説のみ、`n>=30`, baseline `n>=150`、学習時と同じ増減方向なら固定。検証期間の有意性検定は選抜条件に使わない。 |
| テスト | 2023–2025 | 固定仮説のみ、`n>=50`, baseline `n>=150`。方向を固定した片側z検定、テスト対象全仮説でBH補正 `q<=0.05`。件数不足は`p=1`でfamily内に維持。 |

ベースラインは同じ期間・芝ダ・距離帯・競馬場・クラスの**全正常完走馬**（評価対象の血統群を内包）。その包含による依存は分散の群×ベースライン共分散項で補正しています。

同一馬の複数出走を独立試行として数えず、同一馬IDごとに残差を集計したhorse-cluster sandwich分散で勝率・3着内率の**群−ベースライン差**のSEを推定します。レース単位の共有ショック、馬を跨ぐ競争依存、年間変動、クラスタ数が少ない場合の正規近似誤差までは解消しません。
