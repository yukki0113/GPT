## 1. 対象と独立した母集団

- 選定母集団：2022〜2024年生まれ12,018頭の父/母父共通ランキング上位50名（③-A/③-B研究原本）。
- **結果母集団は上記12,018頭の出走実績ではない**。別のJRDB Analysis v1.4に収録された2016-01-05〜2026-11-01のJRA歴史結果を、父名/母父名の**厳密一致**で集計する。出生年別の事後選抜を含むため、過去の各時点からの事前予測の公平な検証ではない。
- 結果正本：JRDB Analysis v1.4 `CURRENT` generation `analysis-v1_4-postrace-20261101-01`。11年別Parquet、manifest全パーティションのSHA-256を照合。
- 上位50の固定入力：`stage3b_top50_master_research.json` SHA-256 `89d01e2c05af27a929c8398ef9e94660f5f1e442362d458383db6e6a9bd7bdc0`。
- 成績の元データは第三者ライセンス/大容量のためGitHubにコミットしない。コード、テスト、集計値の要約のみをGitHubへ保存する。

## 2. 集計方式

- 取消・除外を出走数から除く。公式abnormal code `0/3/4/5/6`を出走分母とし、勝ち/3着内は`0/5`かつ公式着順で集計。出走と一意馬数を別々に返し、`race_key + horse_id`重複は実行を停止する。
- 父 `SIRE`、母父 `BMS`、父×母父 `PAIR`は**別レーン**。同一出走が複数レーンに現れるため、出走件数の足し算を禁止する。
- 条件軸：芝/ダート (`track_type`)、実距離、非重複の4距離帯（〜1399 / 1400〜1799 / 1800〜2399 / 2400m〜）、競馬場コード、馬場状態**原コード**。馬場コードは意味を勝手に解釈せず、芝/ダートと分離した原値で保持。
- 同一条件全体の公式出走母数を比較基準として、勝率・複勝率・Wilson95%区間・基準複勝率・率差（百分点）を計算する。
- 状態：`DESCRIPTIVE` = 30走以上かつ一意馬10頭以上（**適性が確認された意味ではない**）。それ未満 `LOW_SAMPLE`。動的な細分化スコープは観測の存在する組のみ出力するため、「セルがない」を適性なし/0走と同一視しない。
- 近親/他の種牡馬の代理プールなし。系統コード・名前だけから祖先IDを推測せず、③-C/④でID未解決の内包血統は特徴量として参加させない。

## 4. 時期分割による診断

同じ固定結果世代から、**2016-01-01〜2023-12-31**（372,982走）と**2024-01-01〜2026-11-01**（130,778走）を互いに重ならない期間で再集計。上位50の父・母父、芝ダ×距離帯のセル631を比較。

| 観測の比較状況 | セル数 |
|---|---:|
| 両期間でサンプル閾値を満たし、平均との差の符号が同じ | **185** |
| 両期間でサンプル閾値を満たし、符号が逆転 | **105** |
| 一方または両方の母数不足 | **166** |
| 一方の期間に観測セル自体がない | **175** |
| 合計 | **631** |

この診断は効果量・予測精度・有意差の保証ではない。母数/馬の分布、年代による種牡馬供用世代、出走条件の選択、馬の実力や陣営選択の交絡を補正したものではない。符号一致を血統適性の確定として採用しない。
