## 5. 近縁の父の代理集計を採用しない理由

同じ履歴期間における**芝1800〜2399mの産駒複勝率**:

- ディープインパクト: **5,800走 / 3着以内2,062回 = 35.6%**
- ブラックタイド: **1,464走 / 3着以内280回 = 19.1%**

観測集団の異なる比較であり血統効果の因果推定ではないが、**近縁だから統計を代入してよいという推論は成立しない**。父の参考データ不足は不足のまま示し、母父側を別証拠として添える。父の血統系統・類似血統を使う補完は別途、父単位の時系列検証が必要。

### ①の検索スコープ（狭→広）

| 順位 | 内部キー | 意味 |
|---|---|---|
| 1 | `VENUE_COURSE_EXACT` | 同競馬場・**同芝ダ**・同距離・同コースコード |
| 2 | `VENUE_DISTANCE` | 同競馬場・**同芝ダ**・同距離 |
| 3 | **`VENUE_BAND`（追加）** | 同競馬場・**同芝ダ**・同距離帯 |
| 4 | `ALL_VENUES_DISTANCE` | 全競馬場・**同芝ダ**・同距離 |
| 5 | `ALL_VENUES_BAND` | 全競馬場・**同芝ダ**・同距離帯 |

**全スコープで対象の芝/ダート区分を固定する。** 芝2000mの情報不足を、同場ダート2000mで埋めることはない。

ここで「同競馬場・距離帯」とは同一競馬場における1800〜2399m等を指す。同一コース形態のまま距離が変わることを保証する分類ではないため、対象コースへの外挿・スコア算出は行わず、広い条件を参照した**別の観測結果**として返す。

### 責務・出力方針の訂正

- BRDBは、各スコープの**実績・母数・ステータス・区間・条件の広さ**を列挙して返す。条件を広げた結果を狭い条件へ補完・代入しない。
- v0.1にあった `best_supported_scope` はv0.2で廃止。サンプル数の閾値を超えたスコープを**自動採用・優先する判定**は行わない。
- `DESCRIPTIVE` は暫定件数条件を満たすことを示すだけで、適性が十分と認められた状態ではない。少数例は `LOW_SAMPLE`、0走は `NO_SAMPLE`、勝率・複勝率は0走の場合 `null`。
- 父の実績不足を父系類似種牡馬・母父側・他会場の結果で強制的に埋めない。
- **RaceNoteが受け取った後、どう予想へ使うかはRaceNote側の責務。** BRDB側に勝率推定・印・予想ランク付けは置かない。⑤全馬比較も、将来実施するなら根拠の網羅性/品質を比較することと競走結果予測を分離する。
- Synthetic 回帰テスト4件PASS。新規追加は、芝・ダート混在、同場別距離帯、別会場同距離、同場別コースというケースを同時に検証するもの。
- 同じ8頭のParquet実再集計（5スコープ、他は従来②）は 3回合計 **844.4 / 602.7 / 522.6 ms**（初回/再実行、Driveダウンロードを除外）。
