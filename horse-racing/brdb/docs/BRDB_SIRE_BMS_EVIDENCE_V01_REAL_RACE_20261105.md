## 1. 今回完成した範囲

①父産駒について、対象PACIレースの全馬を父名と照合し、(a) 同競馬場・同コース・同距離、(b) 同競馬場・同距離、(c) 全場・同距離、(d) 全場・同距離帯の4階層について実績を返す。

②母父について、対象レース全馬の母父名と照合し、芝/ダート2区分および芝/ダート×4距離帯（SHORT: 1399m以下、MILE: 1400〜1799m、MIDDLE: 1800〜2399m、LONG: 2400m以上）の実績を返す。

どちらも**一意馬数、出走回数、勝利数、3着内数、勝率、複勝率、同条件全体の基準値、複勝率差、Wilson95%区間、サンプル不足フラグ**を出す。①の条件拡張は独立した参考値であり、狭い条件を推定で埋めない。

**芝型/ダート型などの分類ラベルや⑤順位はまだ付与しない。** 母父側のデータは父の欠損を置き換えず、別の独立した判断根拠として返す。近縁種牡馬の成績も自動合算しない。

## 5. 近縁の父の代理集計を採用しない理由

同じ履歴期間における**芝1800〜2399mの産駒複勝率**:

- ディープインパクト: **5,800走 / 3着以内2,062回 = 35.6%**
- ブラックタイド: **1,464走 / 3着以内280回 = 19.1%**

観測集団の異なる比較であり血統効果の因果推定ではないが、**近縁だから統計を代入してよいという推論は成立しない**。父の参考データ不足は不足のまま示し、母父側を別証拠として添える。父の血統系統・類似血統を使う補完は別途、父単位の時系列検証が必要。

## 6. 性能・テスト

環境はCPython 3.13 / DuckDB 1.1.3。DuckDB wheelは過去の検証済みActions run 41748491405にあるものを使用しSHA256を照合した。

PACI以外の初期ダウンロードは含めない。8頭、11年別Parquet manifest/SHA検証、約52万登録行からの事前出走履歴抽出、父4条件・母父10条件の集計を含めた3回実測:

- 初回: **845.5ms**
- 2回目: **539.3ms**
- 3回目: **533.7ms**

従前の馬ごとの個別SQL（約15秒）を、同名の父・母父をまとめて条件別集計する方式へ変更。母数・分析対象数による変動あり。

合成回帰テスト: **3/3 PASS**。対象日未来結果除外、取消/中止の出走処理、母父芝ダ、ゼロ/少サンプル、manifest SHA改ざん拒否を確認した。

今回の本体Analysis集計では、PACIレース抽出部分のみ別の検証用ハーネスを用いた。正本JRDB Parserの直接CLI入出力を含む完全なEnd-to-End試験は**未実施**。この境界を越えて「全経路完了」とは扱わない。
