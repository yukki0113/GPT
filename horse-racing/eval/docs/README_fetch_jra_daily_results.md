# fetch_jra_daily_results

指定したJRA開催日のレース結果・払戻を取得し、1つのCSVへ出力するモジュールです。

## 目的

Eval表の検証・運用台帳への結果取込用として、開催日単位で以下を取得します。

- 会場
- R
- レース名
- 枠順確定時の出走頭数
- 1〜3着の馬番・馬名
- 各種払戻
- 取得元URL
- 取得状態・エラー詳細

## 取得元

Yahoo!スポーツの競馬ページを利用します。

主な取得ページ:

- 月間開催スケジュール
- 開催日のレース一覧
- 各レース結果ページ

## 動作環境

- Python 3
- `requests`
- `beautifulsoup4`
- `urllib3`

インストール例:

```bash
pip install requests beautifulsoup4 urllib3
```

## 基本実行形式

### 日付を個別指定

```bash
python fetch_jra_daily_results.py --dates YYYY-MM-DD [YYYY-MM-DD ...]
```

例:

```bash
python fetch_jra_daily_results.py --dates 2026-08-22 2026-08-23
```

### 期間指定

```bash
python fetch_jra_daily_results.py --from YYYY-MM-DD --to YYYY-MM-DD
```

例:

```bash
python fetch_jra_daily_results.py --from 2026-08-22 --to 2026-08-23
```

## オプション

### `--output-dir`

CSV出力先ディレクトリを指定します。

既定値:

```text
output
```

例:

```bash
python fetch_jra_daily_results.py   --dates 2026-08-22 2026-08-23   --output-dir output_results
```

### `--interval`

レースページ等へのアクセス間隔を秒で指定します。

既定値:

```text
0.7
```

例:

```bash
python fetch_jra_daily_results.py   --dates 2026-08-22   --interval 1.0
```

## 出力ファイル名

1日指定:

```text
YYYYMMDD_JRA結果払戻.csv
```

複数日・期間指定:

```text
YYYYMMDD-YYYYMMDD_JRA結果払戻.csv
```

## 出走頭数の仕様

`出走頭数` は「実際に走った頭数」ではなく、**取消・競走除外前の枠順確定時の頭数**を保持することを目的としています。

Yahoo!スポーツの結果表では、取消・競走除外となった馬も枠番・馬番を持つ行として残るため、

- 着順が数値の行数

ではなく、

- 馬番が数値として存在する行

をすべて数え、重複しない馬番数を出走頭数としています。

これにより、Eval表作成時点に近い「枠順確定時の母数」を保持します。

## 払戻対象

以下を取得します。

- 単勝
- 複勝
- 枠連
- ワイド
- 馬連
- 馬単
- 3連複
- 3連単

同一券種に複数の払戻行が存在する場合は、` / ` 区切りで1セルに格納します。

## エラー処理

各レースについて、

- 成功時: `取得状態 = 成功`
- 取得・解析失敗時: `取得状態 = 失敗`

とし、詳細を `エラー詳細` に記録します。

HTTPアクセスにはリトライ処理があり、主に以下のHTTPステータスを再試行対象としています。

```text
429
500
502
503
504
```

## 開催日の扱い

`--dates` で明示した日付にJRA開催を検出できなかった場合は異常終了します。

`--from` / `--to` の期間指定では、JRA開催がない日をスキップして処理を継続します。
