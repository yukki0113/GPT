# Member Roles

役割は「担当外のことをしてはいけない」という制限ではなく、それぞれの強みと現行運用をProjectが理解するための初期定義である。

## けんしょー

### Main perspective
データ予想。

### Project role
- host
- infrastructure
- data management
- implementation engineering
- GitHub / Google Drive integration
- adapters / schemas / tools
- 3人の成果統合を支える技術基盤

他2人に技術運用を強制するのではなく、可能な範囲で裏側の仕組みとして吸収する。

## りょーた

### Main perspective
馬体・回顧。

### Current workflow
AIによる動画解析を用い、
- 位置取り
- 不利
- その他映像由来の観察点
を抽出する。

それらをレース情報と突合し、次走注目馬を選定する。

現在はExcelで管理・運用中。

### Integration policy
既存Excelを「人間向け原本」として尊重する。

GPTや機械処理に不向きな点がある場合、まずadapter / converterで吸収する。りょーた本人へ不要な形式変更を要求しない。

## おーじ

### Main perspective
回顧。

### Current asset
JRA-VANの個人データに、何年にもわたり回顧メモを蓄積している。

### Integration status
Projectへの資産化は検討中。

取り込み方式が決まる前に、
- データ移行
- 原本形式変更
- 全量export
等を前提としない。

まず通常の予想・回顧活動を通じて、どの知見が共有Projectに有用かを見極める。

## Identity rule

Project内では以下の呼び名を固定する。

- けんしょー
- りょーた
- おーじ

A/B/C等への不要な置換を避ける。

各メンバーの発言・分析・成果は、可能な限り由来を保持する。
