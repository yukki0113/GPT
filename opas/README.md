# OPAS改善提案プロジェクト

大阪市の公共スポーツ施設予約システム OPAS（reserve.opas.jp）について、実利用者の一次情報と公開資料を基にUX課題を監査し、スマートフォン向け改善案・独立デモ・提案資料へ落とし込むプロジェクトです。

## 目的

- 現行画面・操作フローを事実ベースで監査する
- 実画面確認済み事項、公式資料上の記述、推測・改善仮説を分離する
- P0（主要導線）から順に画面要件を確定する
- 実OPASとは接続しない独立デモを作成する
- 改善提案の案件化・有償受注可能性を検討する

## 管理方針

### GitHub（本リポジトリ）
テキスト資産・設計資産の正本。

- 課題台帳
- 現行画面の確認済み事実
- 調査環境上の制約
- P0/P1/P2要件
- Work向け指示書
- 将来の独立デモ実装

### Google Drive
スクリーンショット、参考資料、提案用バイナリの保管先。

- 01_実機調査SS
- 02_参考資料
- 03_提案素材

## 現在の優先度

### P0
1. スマホファーストのログイン導線
2. 空き状況カレンダーのレスポンシブ化・選択UI
3. 検索・候補選択から予約申込／最終確認までの操作フロー

### P1
予約照会・取消、抽選関連、お気に入り、ナビゲーション。

### P2
利用者登録・資格確認・更新・本人確認・口座振替等の制度・業務プロセス。

## 作業原則

- 未確認仕様を事実として書かない
- 認証情報・暗証番号・個人情報をリポジトリへ保存しない
- 実機調査で予約確定・取消・利用者情報変更等の状態変更を行わない
- 大量アクセス、スクレイピング、認証回避、非公開API調査を行わない
- 実サービスの画面・ロゴ等の権利に留意し、公開デモはダミーデータで構成する
