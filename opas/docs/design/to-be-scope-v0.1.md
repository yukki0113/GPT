# OPAS To-Be設計スコープ v0.1

更新日: 2026-10-13

## 目的

全画面再設計ではなく、高頻度かつ実機で課題が確認できた主要導線に改善提案を集中する。

## 詳細モック対象

### 1. ログイン前トップ
- ログイン/空き照会をファーストビュー近傍へ
- お知らせは要約・優先度付け

### 2. 空き照会・予約
- 横長表を日付/施設単位のカード・リストへ
- 同日複数時間帯選択は維持
- 複数日不可は事前提示

### 3. 抽選申込
- 「いつもの条件」の再利用
- 1区分制約・申込残数を選択前に提示
- 時間帯指定/時間帯任意を明示的に分岐

### 4. 抽選結果照会・確定
- 一覧をカード化
- 期限・状態を優先表示
- 業務上許容される場合の一括確定/辞退を検討

## 簡易改善対象

- 予約照会・取消: 1予約1カード、横スクロール排除
- 利用者設定変更: カテゴリ分け、長い値の折返し/全文表示

## 共通設計原則

- 横スクロールを主要操作にしない
- 最終確定の重要確認は残す
- 制約は後出しエラーではなく事前ガイダンスへ
- 高頻度反復操作を短縮する
- 制度変更とUI改善を分離して扱う
