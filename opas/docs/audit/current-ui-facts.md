## ログイン前トップ

- スマートフォン実機は iPhone 16。
- 初期表示上部にOPASロゴ、DigiCert表示、お知らせ領域がある。
- お知らせは複数カードが縦方向に続く。
- 上部に「ページの最後へ」ボタンがある。
- お知らせ途中に「利用者登録の更新について」がある。
- 同案内には、所定の手続きが必要で通常約2週間程度かかる旨が表示されている。
- 「ログインについての注意」の後に利用者番号・パスワード入力欄とログインボタンがある。
- ユーザー実測では、初期表示からログイン欄までおよそ13スクロール。
- ログイン欄より下に、未登録者等も利用できる「空き状況照会」等の照会系ボタンがある。

## ログイン後：更新期限警告

- 更新期限が近い利用者では、通常メニューの前に専用の「利用者更新期限のお知らせ」画面が挟まる。
- 2026-10-09撮影時、画面には期限として「2026年11月30日」が表示されていた。
- 継続利用する場合、期限までに「施設を管理している団体窓口で継続申請処理」を行うよう案内される。
- 期限までに処理しない場合、一時停止となりシステムを利用できなくなる旨が表示される。
- 画面下部に「次に進む」ボタンがある。

## 空き状況照会・予約

確認できた遷移例:

1. 照会方法選択
2. 利用目的選択（大分類）
3. 利用目的選択（小分類）
4. 施設絞り込み（場所選択）
5. 施設別空き状況照会
6. 申込内容入力

今回の例では、利用目的から絞り込み、テニス → 硬式テニス → 複数施設選択と進んだ。

- 施設選択画面では複数施設を選択できる。
- 施設選択表はiPhone 16の画面幅を超え、右側の情報が見切れる。
- 施設別空き状況照会は、日付を横軸、時間帯を縦軸にした表形式。
- 空き状況表もiPhone 16の画面幅を超え、横方向に情報が続く。
- 複数施設・コートの空き状況表が縦方向に連続する。
- 同一利用日の複数時間帯は同時選択できる。
- 10月10日の09:00〜10:00と10:00〜11:00を選択した例では、申込内容入力画面に両時間帯が表示された。
- 異なる利用日を同時選択した場合、「複数の利用日を同時に申込できません」とメッセージが表示される。

## 申込内容入力

- 選択した施設名、日付、区分（時間帯）、面数が表で表示される。
- 今回の例では、南港中央庭球場ハードコート、10月10日、09:00〜10:00・10:00〜11:00、1面が表示された。
- ジャンルは「硬式テニス」と表示される。
- 利用人数の入力欄がある。
- お気に入り登録の選択肢がある。
- 画面上部および下部に「前に戻る」「次に進む」がある。
