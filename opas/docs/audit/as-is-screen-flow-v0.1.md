# OPAS As-Is画面遷移設計書 v0.1

更新日: 2026-10-13

## 主要機能

- ログイン前トップ
- 利用者更新期限通知
- 空き照会・予約
- 予約照会・取消
- 利用実績照会
- 抽選申込
- 抽選結果照会・確定/辞退
- 利用者設定変更

## 主要遷移

### 空き照会・予約
照会方法選択 → 利用目的（大分類）→ 利用目的（小分類）→ 施設選択 → 空き状況照会 → 申込内容入力

確認済み:
- 複数施設選択可
- 同一利用日の複数時間帯選択可
- 異なる利用日の同時申込不可
- 施設選択表・空き状況表はiPhone 16で横幅超過

### 予約照会・取消
予約一覧照会 → 予約詳細確認 → 取消完了

確認済み:
- 一覧・詳細とも横長表で横スクロールが必要

### 抽選申込
申込方法選択 → 利用目的（大分類）→ 利用目的（小分類）→ グループ選択 → 場所選択 → 抽選申込対象選択 → 申込内容確認 → 完了

確認済み:
- 複数区分（時間帯）選択不可
- 一利用日の申込制限回数あり
- 時間帯任意ルートあり
- 制約違反は操作後のエラーで通知

### 抽選結果照会・確定/辞退
申込/結果照会一覧 → 内容照会 → 当選確定系 または 辞退確認 → 完了

確認済み:
- 一覧で1件ずつ選択
- 確定/辞退も1件単位
- 当選未確定分には期限表示
- 結果一覧もスマホ幅超過

### 利用者設定変更
設定変更処理選択 → 登録内容確認ほか各設定

確認済み:
- 当該メニュー内に利用者登録継続申請/会員更新項目は確認できない
- 長い登録値がスマホで全文確認できないケースあり
- メニューは縦長

## システム横断課題

1. PC向け横長表が主要機能を横断してスマホへ持ち込まれている
2. 抽選の申込・結果処理に1件単位の反復操作が多い
3. 業務制約が後出しエラーになっている
4. ログイン前トップで主要導線到達距離が長い
5. 長い登録値の表示欠落がある
