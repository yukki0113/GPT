# 競艇・会場特性マスタ Ver0.1

## 目的

会場選別と事前予想で参照する固定の自作資料。BOAT RACE公式「ボートレース場データ」の最近3ヶ月のコース別入着率を一次情報とし、外部予想・当日結果・オッズ等は混ぜない。

- 基準期間: 2026/05/01～2026/07/31
- 更新方針: 原則月1回。バックテストでは当時利用可能だった版を固定する。
- 会場選別: 開催日目・既存運用ルールを先に見た上で、同程度の候補場間の補正として利用する。
- 予想: 個別選手比較が主。会場特性は1号艇を不用意に落とさない／非1号艇Aを過剰昇格させない補助材料とする。

## Ver1.2.2検討への接続

現行の前向き検証データにこの会場区分を後付けし、1号艇A・2号艇A・3号艇Aの軸成功率／主推奨的中率／回収率を会場区分別に再集計する。会場特性だけでAを作るのではなく、非1号艇Aの昇格条件と1号艇Aの保護条件の補助変数として扱う。
