# 競艇AI予想 事前予想仕様書

Version 1.2.1  
改訂日: 2026-08-11

---

# 目的

本仕様書は、競艇AIによる**事前予想**の基準、買い目生成手順、CSV出力仕様および出力前検査を定義する。

予想は開催前に取得可能な情報のみを使用し、バックテストにおいても常に同一条件で再現できることを目的とする。

本Version 1.2.1は、Version 1.2の相対比較思想・買い目生成思想・24列CSV・予想根拠明細CSVを維持したまま、2026-08-09を用いたVer.1.1→Ver.1.2判定差分監査を踏まえ、**A判定に残すための条件と例外Aの記録要件を明確化し、第三者が同一入力から同一判定を再現しやすくする**ことを目的とする。

Version 1.2.1での主な変更点は以下とする。

- Version 1.2で導入した1号艇基準の相対比較・軸警戒・6艇構造化保存は維持
- 軸警戒の1号艇をA判定に残す場合の追加根拠を明確化
- 非1号艇をA軸とする場合の最低条件と追加条件を明確化
- 4〜6号艇をA軸とする場合、能力比較とは別に具体的展開根拠の記録を必須化
- 「相対評価が明確」「4点に整理できる」だけでは、B/CからAへ昇格させる十分条件としないことを明文化
- 4点化・2着/3着候補選定ルール、24列予想CSV、予想根拠明細CSVは変更しない

2026-08-09の判定差分監査では、Ver.1.2でAが31Rから52Rへ増加し、その主因は相対比較の導入自体ではなく、**A維持・A昇格に必要な追加根拠の強度が未定義で裁量幅が大きかったこと**と確認された。さらに4〜6号艇Aの6Rでは、Ver.1.2が必須としていた「非1号艇頭とする具体的な展開根拠」が判定理由に記載されていなかった。

そのためVersion 1.2.1では、結果やA本数に合わせた閾値調整は行わず、Version 1.2の意図を第三者が再現できる最低限の判定手順へ置き換える。

# 既存予想データの扱い

Version 1.2への改訂は、Version 1.1までに確定済みの予想、判定、主推奨買い目を遡って変更するものではない。

Version 1.0またはVersion 1.1明文化前に作成した予想も、以下を満たす限り有効なバックテストデータとして扱う。

- 使用禁止情報を参照していない
- 結果確認前に予想が確定している
- 判定および買い目を結果確認後に変更していない
- 主推奨買い目展開後と主推奨点数が確定している

評価区分列の表記ゆれや分類上の不整合のみを修正した場合、主推奨買い目・保険買い目・判定が変わらなければ、予想の差し替えとは扱わない。

既存データの集計では、購入対象の正本を以下とする。

1. 主推奨買い目展開後
2. 保険買い目
3. 参考買い目

評価区分列は、予想構造の分析および説明用メタデータとして扱う。

# 1着軸選定基準（Version 1.2追加）

1着軸は、単独の級別・勝率・ST・モーター・今節成績だけで決定してはならない。

必ず6艇を比較し、特に**1号艇のコース優位を基準にした相対評価**を行う。

## 共通原則

1. まず1号艇を基準艇として評価する。
2. 非1号艇を1着軸候補とする場合は、1号艇を上回る根拠を明示する。
3. 全国勝率、当地勝率、平均ST、モーター2連率、今節成績、級別を総合して比較する。
4. 単一項目だけの優位を理由に、1号艇から非1号艇へ機械的に軸を変更しない。
5. 1着軸の選定理由には、1号艇との比較内容を必ず記載する。
6. 結果確認後に相対評価や軸選定理由を修正してはならない。

## 1号艇を1着軸とする場合

1号艇を1着軸とする場合、非1号艇のうち事前情報上もっとも強い艇を「最強非1号艇」として固定規則で選定し、比較する。

最強非1号艇の決定順は以下とする。

1. 全国勝率が高い艇
2. 同値の場合は当地勝率が高い艇
3. 同値の場合は級別が高い艇
4. 同値の場合は平均STが小さい艇
5. 同値の場合はモーター2連率が高い艇
6. 同値の場合は今節平均着順が小さい艇
7. なお同値の場合は艇番が小さい艇

1号艇の全国勝率が最強非1号艇より低い場合は、**軸警戒**として扱う。

軸警戒は自動的なB降格条件ではない。

ただし、軸警戒の1号艇をA判定に残す場合は、以下を必須とする。

- 1号艇を維持する追加根拠を**少なくとも2項目**、判定理由へ明記する
- そのうち**少なくとも1項目**は、当地勝率・平均ST・モーター2連率・今節成績のいずれかについて、比較相手より1号艇を評価できる内容とする
- 進入利・1コース優位のみをA維持の根拠としてはならない
- 「相対評価が明確」「相手を4点へ整理できる」だけではA維持の追加根拠として数えない

上記を満たせない場合はB以下とする。

## 非1号艇を1着軸とする場合

非1号艇を1着軸とする場合は、少なくとも以下を必ず確認する。

- 軸艇全国勝率と1号艇全国勝率
- 軸艇当地勝率と1号艇当地勝率
- 軸艇平均STと1号艇平均ST
- 軸艇モーター2連率と1号艇モーター2連率
- 軸艇今節成績と1号艇今節成績
- 軸艇級別と1号艇級別

非1号艇をA判定の1着軸とする場合は、**全国勝率・当地勝率の両方で1号艇を上回ることを原則条件**とする。

さらに、以下のいずれかを満たすことを必須とする。

- 平均ST・モーター2連率・今節成績・級別のうち、**2項目以上**で1号艇より優位である
- または、能力比較だけでは説明できない**具体的な展開根拠**があり、その内容を判定理由へ記載できる

全国勝率・当地勝率の両方で1号艇を上回っていても、それだけでA判定または1着軸を自動確定してはならない。
また、「相対評価が明確」「相手を4点へ整理できる」だけではA昇格の十分条件としない。

全国勝率または当地勝率のいずれかで1号艇を下回る非1号艇をA判定の1着軸とする場合は例外判断とし、上記の具体的展開根拠に加え、コース不利を覆す複数の比較優位を判定理由へ明記する。これを満たせない場合はB以下とする。

## 4〜6号艇を1着軸とする場合

4〜6号艇の1着軸は展開依存度が高いため、A判定では例外扱いとする。

以下を満たさない場合は原則B以下とする。

- 1号艇との相対比較を実施している
- 全国・当地・ST・モーター・今節成績の複数項目で優位性を説明できる
- 主推奨4点以内に展開を整理できる
- 能力比較とは別に、判定理由へ**「1号艇の不利要因」**を具体的に1点以上記載する
- 能力比較とは別に、判定理由へ**「軸艇が1着になる想定進行」**を具体的に1文以上記載する

「複数項目で優位」「相手を4点へ整理できる」だけでは4〜6号艇の例外Aを成立させない。
上記2種類の展開記載を行えない場合は原則B以下とする。

5号艇・6号艇については特に慎重に扱う。
ただし、現時点の検証母数では一律禁止を仕様化する根拠は不足しているため、禁止条件とはしない。

# A判定基準

以下をすべて概ね満たすこと。

- 1着軸選定基準に基づく相対評価を行い、軸の根拠を説明できる
- Ver.1.2.1で定める軸警戒A・非1号艇A・4〜6号艇Aの追加条件を、該当時にすべて満たしている
- 「相対評価が明確」「相手を4点以内に整理できる」ことだけを理由に、Ver.1.1相当のB/C条件をAへ昇格させていない
- 軸候補の進入・スタートに大きな不安がない
- 相手を原則2〜3艇へ絞れる
- 展開予想が複数パターンへ大きく分岐しない
- 主推奨買い目を原則4点以内へ整理できる

A判定で4点を超える場合は、点数増加の合理的理由を判定理由へ明記する。

条件を満たせない場合は、BまたはCへ評価を下げる。

---

# B判定基準

軸または中心艇は置けるが、次のいずれかがある場合はBとする。

- 相手比較が拮抗している
- 進入またはスタートに不安がある
- 頭逆転を含める必要がある
- 主推奨が5〜6点程度になる
- 外枠軸など、展開依存度が比較的高い
- 1着軸の相対優位が十分に説明できない
- A判定とするには信頼度が不足する

---

# C判定基準

以下のいずれかに該当する場合はCとする。

- 1着軸または連軸を合理的に定められない
- 展開分岐が多い
- 相手候補が広すぎる
- 主推奨を6点以内へ整理できない
- リスクに対して購入根拠が弱い

C判定では主推奨および保険を設定しない。  
参考買い目のみ設定してよい。

# 買い目設計方針

買い目は、**券種の固定点数から逆算して作成しない。**

まず以下を評価する。

- 軸評価
- 相手評価
- 着順評価
- 逆転可能性
- 展開分岐

その評価から自然に買い目を生成する。

作成順序は以下とする。

1. 各艇の評価を行う
2. 評価区分を決める
3. 主推奨買い目表記を作る
4. 買い目表記を個別買い目へ展開する
5. 展開後買い目から各着順に使用される艇を確認する
6. 評価区分列との整合性を検査する
7. 展開後買い目数を主推奨点数として記録する
8. 全項目を検査後にCSVを確定する

# 艇評価区分

評価区分は排他的ではない。  
同一艇が複数の役割を持つ場合、複数列へ重複して記載してよい。

## 1着軸

主推奨の基本シナリオで1着中心となる艇。

1着固定型では、その艇がすべての主推奨買い目で1着となる。

## 連軸

1着固定まではできないが、2連対の中心となる艇。

主としてC判定または1着固定が難しい予想構造で使用する。

1着軸を設定したA・B判定では、原則として空欄とする。

## 2着本線

主推奨買い目で2着に使用する中心相手。

逆転候補と同一艇になることがある。

例:

```text
1⇔3→2,4
```

この場合、3号艇は`2着本線`かつ`逆転候補`である。

## 2着押さえ

主推奨買い目で2着に使用するが、2着本線より評価が低い艇。

本線相手と同格に扱わず、展開上残す必要がある場合のみ設定する。

2着に一度も使用しない艇を記載してはならない。

## 逆転候補

1着軸を上回って1着になる買い目を、実際に主推奨として購入する艇。

単に能力上位または頭可能性があるだけでは記載しない。  
主推奨買い目展開後で1着に使用されていることを必須とする。

1着固定型では空欄とする。

## 3着候補

主推奨買い目展開後で3着に使用されるすべての艇。

2着本線、2着押さえ、逆転候補と重複してよい。

例:

```text
1→2,3→2,3,4
```

この場合は以下となる。

```text
1着軸: 1
2着本線: 2,3
3着候補: 2,3,4
```

2号艇と3号艇は2着・3着の両方に使用されるため、両列へ記載する。

# 券種別ルール

## 2連複

原則使用しない。

以下の場合のみ、参考買い目または例外的な主推奨として採用する。

- 1着固定が難しい
- 2艇とも2連対する可能性が高い

原則1点、最大2点とする。

## 2連単

1着軸または連軸の関係が明確な場合に使用する。

基本形:

```text
軸→相手
```

1〜2点程度を基本とする。

相手側に頭逆転の可能性があり、実際に購入する場合のみ折り返しを追加する。

目安は最大4点とする。

## 3連単

### 1着固定型

```text
A→B,C→B,C,D
```

展開例:

```text
A→B→C
A→B→D
A→C→B
A→C→D
```

### 2・3着入れ替わり型

```text
A→B⇔C,D
```

### 1・2着逆転型

```text
A⇔B→C,D
```

展開例:

```text
A→B→C
A→B→D
B→A→C
B→A→D
```

### 点数

- A判定: 原則4点以内
- B判定: 原則6点以内
- 6点以内へ合理的に整理できない場合は、推奨度を下げるかC判定とする

# 買い目表記ルール

## 区切り文字

- 複数艇: 半角カンマ `,`
- 個別買い目の区切り: 全角スラッシュ `／`
- 着順: 矢印 `→`
- 折り返し: `⇔`
- 2連複: `=`

## 主推奨買い目表記

人が読みやすい圧縮表記を記録する。

例:

```text
1→2,3→2,3,4
1⇔3→2,4
```

## 主推奨買い目展開後

実際に購入対象となる個別買い目を、すべて列挙する。

例:

```text
1→2→3／1→2→4／1→3→2／1→3→4
```

`主推奨買い目展開後`を、的中判定および購入点数算出の正本とする。

## 主推奨点数

主推奨買い目展開後に列挙した個別買い目の件数と完全一致させる。

## 保険買い目

圧縮表記を使用せず、原則として個別買い目を全角スラッシュで区切って記載する。

## 参考買い目

C判定または通常購入しない補助的買い目を記載する。  
主推奨・保険の正式収支には含めない。

評価:

- 1着軸: 1

- 3着候補: 2,3,5

- 1着軸: 1

```text
1⇔3→2,5

主推奨買い目展開後:
1→3→2／1→3→5／3→1→2／3→1→5

主推奨点数:
4
```

評価:

- 1着軸: 1
- 2着本線: 3
- 2着押さえ: 4

```text
4
```

```text
0
```

# 券種の位置付け

## 主推奨券種

収支集計の中心となる買い方。

## 保険券種

主推奨とは別券種または別構造で、的中率を補完する買い方。

## 参考券種

理論上成立するが、通常は正式購入対象としない買い方。

複数券種を機械的に同時購入することは行わない。  
主推奨、保険、参考は明確に区分する。

# 予想根拠明細CSV（Version 1.2追加）

Version 1.2以降は、従来の24列予想CSVとは別に、**予想確定時点の6艇事前情報を構造化保存する明細CSV**を必須とする。

目的は、結果確認後に理由文から数値を復元する必要をなくし、軸成功/失敗を同一条件で再検証できるようにすることである。

## 保存単位

1レース6行、1艇1行とする。

## 必須列

以下の列を、この順序を基本として保存する。

1. 日付
2. 会場
3. R
4. 開催日目
5. 艇番
6. 級別
7. 全国勝率
8. 当地勝率
9. 平均ST
10. モーター2連率
11. 今節成績
12. 今節平均着順
13. 1着軸フラグ
14. 2着本線フラグ
15. 2着押さえフラグ
16. 逆転候補フラグ
17. 3着候補フラグ
18. 1号艇との全国勝率差
19. 1号艇との当地勝率差
20. 1号艇とのST差
21. 1号艇とのモーター2連率差
22. 1号艇との今節平均着順差
23. 1号艇との級別比較
24. 最強非1号艇フラグ
25. 軸警戒フラグ
26. 予想確定日時

相対差は、原則として**正の値ほど当該艇が1号艇より優位**になるよう符号を統一する。

- 全国勝率差 = 当該艇全国勝率 - 1号艇全国勝率
- 当地勝率差 = 当該艇当地勝率 - 1号艇当地勝率
- ST差 = 1号艇平均ST - 当該艇平均ST
- モーター2連率差 = 当該艇モーター2連率 - 1号艇モーター2連率
- 今節平均着順差 = 1号艇今節平均着順 - 当該艇今節平均着順

1号艇自身の相対差は0とする。

値が公式出走表上で空欄の場合は、推測補完せず空欄のまま保存する。

## 軸警戒フラグ

少なくとも以下の場合は軸警戒フラグを立てる。

- 1号艇軸で、最強非1号艇より全国勝率が低い
- 非1号艇軸で、全国勝率または当地勝率のいずれかが1号艇以下
- 4〜6号艇を1着軸とする

軸警戒フラグは判定を自動的に変更するものではない。
A判定とする場合に、追加根拠の明記を要求するための監査用情報とする。

## 保存上の注意

- 予想根拠明細CSVは予想確定時点で保存する
- 結果列、払戻列、オッズ列を含めない
- 後日分析用に結果を結合する場合も、原本は変更しない
- 日付＋会場＋R＋艇番を業務キーとして重複を禁止する

# CSV出力仕様

CSVは以下の24列を、この順序で出力する。

1. 日付
2. 会場
3. R
4. 開催日目
5. レース種別
6. ルールVer
7. 判定
8. 1着軸
9. 連軸
10. 2着本線
11. 2着押さえ
12. 逆転候補
13. 3着候補
14. 主推奨券種
15. 主推奨買い目表記
16. 主推奨買い目展開後
17. 主推奨点数
18. 保険券種
19. 保険買い目
20. 保険点数
21. 参考券種
22. 参考買い目
23. 判定理由
24. 予想確定日時

CSVには行番号用の`index`列を含めない。

空欄項目も列自体は省略せず、全行を24列で統一する。

# 出力前必須検査

CSVを出力する前に、全行について以下を検査する。

## 構造検査

1. ヘッダおよび全データ行が24列である
2. 日付、会場、R、開催日目、判定、ルールVerが空欄ではない
3. 同一の日付・会場・Rが重複していない
4. 対象範囲のRに欠落がない

## 買い目検査

5. 主推奨点数が、主推奨買い目展開後の個別買い目数と一致する
6. 保険点数が、保険買い目の個別買い目数と一致する
7. 個別買い目に同一艇の重複着順がない
8. 主推奨買い目展開後に重複買い目がない
9. 主推奨買い目表記を展開した結果が、主推奨買い目展開後と一致する

## 評価区分検査

10. 逆転候補は、主推奨買い目展開後で実際に1着使用されている
11. 1着固定型では逆転候補が空欄である
12. 3着候補は、主推奨買い目展開後で3着使用される艇の集合と完全一致する
13. 2着本線および2着押さえに記載した艇は、主推奨買い目展開後で実際に2着使用されている
14. 1・2着逆転型では、逆転候補が2着本線にも含まれている
15. A・B判定では主推奨買い目と主推奨点数が設定されている
16. C判定では主推奨点数および保険点数が0である

## 複数日検査

複数日を1CSVへまとめる場合は、日付ごとに以下を検査する。

17. 各日付に1R〜12Rが1件ずつ存在する
18. 開催日目が日付の進行と矛盾していない
19. 日付をまたいだR重複を誤検出しない
20. 予想確定日時が全対象レースの結果参照後であっても、テスト種別が過去バックテストであることを明確にする

## Version 1.2 追加検査

21. 予想根拠明細CSVに各レース6艇が1件ずつ存在する
22. 日付＋会場＋R＋艇番が重複していない
23. 24列予想CSVの1着軸と、予想根拠明細CSVの1着軸フラグが一致する
24. 非1号艇を1着軸とした場合、1号艇との相対差が算出可能な項目について保存されている
25. 1号艇軸で全国勝率が最強非1号艇より低い場合、軸警戒フラグが設定されている
26. 4〜6号艇軸の場合、軸警戒フラグが設定されている
27. 軸警戒があるA判定では、判定理由に追加根拠が記載されている
28. 予想根拠明細CSVに結果・払戻・オッズ等の使用禁止情報が混入していない
29. 軸警戒の1号艇をA判定に残す場合、追加根拠が2項目以上あり、そのうち1項目以上が当地勝率・平均ST・モーター2連率・今節成績の比較項目である
30. 非1号艇をA軸とする場合、全国勝率・当地勝率の両方で1号艇を上回ることを原則確認し、さらにST・モーター・今節成績・級別のうち2項目以上の優位、または具体的展開根拠が記載されている
31. 4〜6号艇をA軸とする場合、「1号艇の不利要因」と「軸艇が1着になる想定進行」が能力比較とは別に判定理由へ記載されている
32. 「相対評価が明確」「4点以内に整理できる」だけをA維持・A昇格の追加根拠として扱っていない

検査で不一致がある場合は、CSVを確定せず、該当日・R・列名・不一致内容を修正してから出力する。

# バックテスト方針

バックテストでは以下を厳守する。

- 当日時点で取得可能だった情報のみ使用する
- 結果を見て評価を変更しない
- 買い目を後から修正しない
- 常に同一ルールで予想を生成する
- 分類列の整合修正と、予想内容の変更を区別する
- 主推奨買い目展開後を購入対象の正本とする
- Version 1.2以降は6艇の予想根拠明細CSVも予想確定時点で保存する
- 軸警戒フラグや相対差も結果確認前に確定する

これにより、実運用可能な精度検証を行う。
