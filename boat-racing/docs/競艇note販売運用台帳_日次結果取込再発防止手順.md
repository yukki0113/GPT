# 競艇note販売運用台帳 日次結果取込再発防止手順

適用開始: 2026-09-06  
対象: Googleスプレッドシート「競艇note販売運用台帳」  
性格: 台帳集計・結果取込の実装手順。予想ロジックおよび販売ルールは変更しない。

## 1. 対象日とfreezeの確定

結果取込の開始時に、次の3つをキーとして照合する。

- 販売記事台帳の記事ID YYYYMMDD
- 事前予想原本のデータID日付
- 販売掲載明細の日付

3者が一致しない場合は書き込まず、差分を報告する。現在時刻、実行日、結果ファイルの保存日を対象日の生成元にしない。

予想確定日時・販売選別確定日時は、各原本のfreeze値を転記する。日跨ぎ実行でも結果取込時刻で上書きしない。複数freeze値が混在する場合は補完せず停止する。

## 2. 集計の分離

- 掲載成績 = 有料 + 無料
- CSVのみ = 全対象・ForwardTrialには含めるが、掲載成績には含めない
- 全対象 = 有料 + 無料 + CSVのみ

したがって、販売記事台帳の掲載投資・払戻・収支・回収率は必ず有料＋無料の再集計と一致させる。

## 3. 構造KPI

対象行ごとに次を判定する。

1. 1号艇頭成功
2. 頭成功行だけで2着候補2艇カバー
3. 頭成功かつ2艇カバー行だけで内側1点成功

分母はそれぞれ、全対象数、頭成功数、2艇カバー成功数とする。前段失敗の後段値は 対象外 とし、分母へ入れない。

## 4. 失敗構造ラベル

新規行で使用する値は次の6種類に限定する。

的中 / 1号艇頭失敗 / 2着候補2艇外 / 内側1点選択ミス / 返還 / 対象外

頭失敗時は2着候補・内側1点を 対象外、頭成功・2着候補外時は内側1点を 対象外 とする。旧値 軸1着失敗、2着候補外 は新規生成しない。

## 5. 完了前の相互検算

次をすべて確認してから完了とする。

- 記事ID、明細日付、予想原本日付が一致
- freeze値が原本と一致
- 有料＋無料の掲載成績が記事行と一致
- 全対象のForwardTrial成績が明細と一致
- 構造KPIの条件付き分母が一致
- 既存日付の値が不変
- #REF!、#VALUE!、#DIV/0! 等の式エラーがない
- 変更履歴に実装修正として1行記録

## 6. 回帰ケース

最低限、次のケースを毎回確認する。

- 2026-09-05のような日跨ぎ結果取込で対象日・freezeが変わらない
- 2026-09-06の掲載9R（有料6R＋無料3R）とCSVのみ5Rが分離される
- 0906の構造KPIが 10/14 → 6/10 → 4/6 になる
- 頭失敗行の後段が 対象外
- 旧失敗ラベルが新規行に残らない
