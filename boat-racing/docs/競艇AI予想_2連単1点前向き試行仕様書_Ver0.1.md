# 1. 目的

本仕様書は、2026-09-01以降の前向き試行において、BOAT RACE公式出走表だけから事前予想を作成し、**1号艇頭の2連単1点**まで絞り込み、さらに結果参照前に販売選別を固定する手順を定義する。

目的は以下の3点とする。

1. 過去結果に合わせて条件を変更せず、真正のforward validationを継続する
2. 「全対象」と「販売掲載候補」を分離して、商品としての選別性能を検証する
3. 予想・販売選別・結果を別ファイルに保持し、結果リークを防ぐ

本仕様書は `競艇AI予想_事前予想仕様書_Ver1.2.1.md` を基礎仕様とする。
ただし、前向き試行の再現性を確保するため、本仕様書で明示した**決定規則については本仕様書を優先**する。

Ver.1.2.1は履歴・一般仕様として保存し、本仕様書によって遡及変更しない。

# 4. 今節平均着順

`今節成績` から数値として取得できる着順のみを使用し、その平均を `今節平均着順` とする。

- 1〜6の数値着順だけを平均対象とする
- 欠場・失格・転覆など、数値着順として安全に解釈できない値は推測補完しない
- 有効な数値がない場合は空欄とする
- 小さいほど良い値として比較する

# 5. 最強非1号艇

1号艇と比較する「最強非1号艇」は、2〜6号艇から以下の固定順で1艇を決定する。

1. 全国勝率が高い
2. 当地勝率が高い
3. 級別が高い
4. 平均STが小さい
5. モーター2連率が高い
6. 今節平均着順が小さい
7. 艇番が小さい

欠損値は推測補完しない。

# 6. 1着軸・A/B/Cの決定規則

## 6.1 非1号艇A候補

前向き試行では、静的な公式出走表だけで具体的な進行根拠を再現するための情報が不足するため、**4〜6号艇をA判定の1着軸にはしない**。

非1号艇をAの1着軸候補とできるのは、2号艇または3号艇で、以下をすべて満たす場合とする。

- 全国勝率が1号艇より高い
- 当地勝率が1号艇より高い
- 以下4項目のうち3項目以上で1号艇より優位
  - 平均ST
  - モーター2連率
  - 今節平均着順
  - 級別

複数艇が条件を満たす場合は、以下の値が大きい艇を1着軸とする。

```text
(当該艇全国勝率 - 1号艇全国勝率)
+
(当該艇当地勝率 - 1号艇当地勝率)
```

同値の場合は艇番が小さい艇を優先する。

この条件を満たした場合はA判定とする。

## 6.2 1号艇軸

6.1の非1号艇A候補が存在しない場合は、1号艇を基準に判定する。

以下5項目について、1号艇が最強非1号艇より優位な項目数を `比較支持項目数` とする。

- 当地勝率: 1号艇の方が高い
- 平均ST: 1号艇の方が小さい
- モーター2連率: 1号艇の方が高い
- 今節平均着順: 1号艇の方が小さい
- 級別: 1号艇の方が高い

また、以下の場合は `軸警戒=あり` とする。

```text
1号艇全国勝率 < 最強非1号艇全国勝率
```

### 軸警戒あり

A条件:

- 比較支持項目数が3以上
- かつ、当地勝率・平均ST・モーター2連率・今節平均着順の4項目のうち2項目以上で1号艇が優位

A条件を満たさず、比較支持項目数が1以上ならB。
比較支持項目数が0ならC。

### 軸警戒なし

- 比較支持項目数3以上: A
- 比較支持項目数1〜2: B
- 比較支持項目数0: C

# 7. 相手総合スコア

AまたはBの相手候補順位を固定するため、レース内6艇を対象に以下の総合スコアを計算する。

| 項目 | 重み | 良い方向 |
|---|---:|---|
| 全国勝率 | 0.35 | 高い |
| 当地勝率 | 0.20 | 高い |
| 平均ST | 0.15 | 小さい |
| モーター2連率 | 0.10 | 高い |
| 今節平均着順 | 0.15 | 小さい |
| 級別 | 0.05 | 高い |

各数値項目は、そのレース6艇内で0〜1へmin-max正規化する。

- 高いほど良い項目: `(値-min)/(max-min)`
- 小さいほど良い項目: `1-(値-min)/(max-min)`
- 全艇同値の場合: 0.5
- 欠損値: 0.0としてスコア加算し、推測補完しない

級別は以下の順序値を用いる。

```text
A1=4
A2=3
B1=2
B2=1
```

総合スコアは各正規化値×重みの合計とする。

---

# 8. 2着本線・2着押さえ・3着候補

AまたはBで1着軸を決定した後、1着軸艇を除く5艇を相手総合スコアの高い順に並べる。

同点の場合は艇番が小さい艇を上位とする。

上位3艇を以下の通り固定する。

```text
1位 = 2着本線
2位 = 2着押さえ
3位 = 追加3着候補
```

3着候補は以下3艇の集合とする。

```text
2着本線,2着押さえ,追加3着候補
```

A/Bの3連単構造は互換性維持のため以下4点とする。

```text
軸→本線→押さえ
軸→本線→追加3着候補
軸→押さえ→本線
軸→押さえ→追加3着候補
```

この3連単4点は予想構造の保存・比較用であり、**ForwardTrial_Ver0.1の商品検証の主対象は後述する2連単1点**とする。

C判定では正式購入対象を作らない。

---

# 9. 2連単1点対象

2連単1点の検証対象とするには、以下をすべて満たすこと。

1. 判定=A
2. 1着軸=1号艇
3. 2着本線が1艇
4. 2着押さえが1艇

対象外のレースは、2連単1点の商品候補にはしない。

---

# 10. 2連単1点の決定

対象レースでは、`2着本線` と `2着押さえ` のうち**艇番が小さい方**を2着として1点だけ選ぶ。

例:

```text
2着本線=5
2着押さえ=3
→ 2連単1点 = 1→3
```

```text
2着本線=2
2着押さえ=4
→ 2連単1点 = 1→2
```

本線/押さえの名称上の序列ではなく、艇番の内側を優先する。

折り返しは行わない。
1レース100円・1点を標準評価単位とする。

# 11. 販売選別スコア

2連単1点対象レースだけを販売選別の母集団とする。

## 11.1 比較支持項目数

6.2で定義した、1号艇が最強非1号艇より優位な以下5項目の件数とする。

- 当地勝率
- 平均ST
- モーター2連率
- 今節平均着順
- 級別

## 11.2 全国勝率差

```text
1号艇全国勝率 - 最強非1号艇全国勝率
```

## 11.3 2着候補の分離度

1号艇を除く5艇を相手総合スコア順に並べ、以下を計算する。

```text
2着押さえ相当の2位スコア - 追加3着候補相当の3位スコア
```

これを `2着候補分離度` とする。

## 11.4 加点

販売スコアは以下の合計とする。

| 条件 | 加点 |
|---|---:|
| 軸警戒なし | +2 |
| 比較支持項目数が5 | +2 |
| 比較支持項目数が4 | +1 |
| 全国勝率差が0.50以上 | +1 |
| 2着候補分離度が0.15以上 | +2 |
| 2着候補分離度が0.08以上0.15未満 | +1 |
| 2連単1点の相手が2〜4号艇 | +1 |
| 2連単1点の相手が2着本線と一致 | +1 |

同じ条件を二重加点しない。
たとえば比較支持項目数5は+2であり、+2と+1を重複加算しない。

---

# 12. 販売順位と掲載区分

対象レースを以下の順で並べる。

1. 販売スコアの高い順
2. 同点なら2着候補分離度の高い順
3. 同点なら会場名の昇順
4. 同点ならRの昇順

順位により以下を固定する。

| 順位 | 掲載区分 |
|---|---|
| 1〜6位 | 有料 |
| 7〜9位 | 無料 |
| 10位以下 | CSVのみ |

候補が9R未満の場合は存在する候補だけを上記順で割り当て、存在しない枠を無理に補充しない。

内部販売評価は以下とする。

- 有料1〜6位: 販売スコア7以上ならS、それ以外はA
- 無料7〜9位: A-
- CSVのみ: A-

この内部評価は販売順位の説明用であり、正式A/B/C判定を上書きしない。

# 14. 保存先

GitHubには仕様・コードを保存し、日次CSVは保存しない。

日次原本はGoogle Driveの `data` 系統を正本とする。

- racecards: 公式出走表
- predictions: 事前予想
- prediction-rationales: 予想根拠明細
- sales-selection: 2連単1点・販売選別
- results: 結果

分析結果・固定スナップショット・検証集計は `data` と同階層の `analysis` に保存する。

# 15. 結果参照前チェック

販売選別確定前に以下を必ず確認する。

1. 当該日のresultsを参照していない
2. 事前予想が全対象R分存在する
3. 予想根拠明細が1レース6行存在する
4. 2連単1点対象条件を機械的に適用している
5. 2連単1点が `1→内側艇` になっている
6. 販売スコアの加点が仕様通りである
7. 同点順位のtie-breakが仕様通りである
8. 有料・無料・CSVのみが順位通りである
9. 予想確定日時と販売選別確定日時が保存されている
10. `結果参照状態=未参照` である

ここまでを保存してから結果を開く。

# 16. 結果測定

結果確認後は、予想・買い目・販売区分を変更せず、以下を測定する。

## Primary

2連単1点対象の全レース。

- 対象R数
- 返還R数
- 的中R数
- 的中率
- 実効投資額
- 払戻額
- ROI

## Secondary

掲載群と非掲載群を分ける。

- 有料
- 無料
- 有料+無料
- CSVのみ

各群について的中率・投資・払戻・ROIを計測する。

## 構造KPI

- 1号艇1着率
- 1号艇勝利時の実2着2艇カバー率
- 2艇カバー時の内側1点的中率

# 17. ルール変更禁止

前向き試行中は、単日結果を理由に本仕様を変更しない。

結果を見た日について、以下を行ってはならない。

- 対象レースを後から追加・削除する
- 2連単1点を変更する
- 販売スコアを変更する
- 掲載区分を変更する
- 会場や艇番条件を後付けする
- 同じ日を改訂版の独立検証として再利用する

改訂が必要な場合は新Versionを作成し、そのVersionは**次の未見日から**評価する。

# 18. Ver.1.2.1との関係

`競艇AI予想_事前予想仕様書_Ver1.2.1.md` は、2026-08-31までの現行事前予想仕様および履歴正本として残す。

- 非1号艇A候補を2・3号艇に限定
- 非1号艇Aの比較条件を固定
- 4〜6号艇Aを試行上は採用しない
- 相手順位を総合スコアで固定
- 2着本線・2着押さえを各1艇へ固定

- 販売選別を定量スコアで固定

したがって、2026-09-01以降の前向き試行を行う予想スレッドは、まず本仕様書を読み、その基礎資料としてVer.1.2.1を参照する。
