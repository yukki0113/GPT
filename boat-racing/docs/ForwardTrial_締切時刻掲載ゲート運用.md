# ForwardTrial 締切時刻掲載ゲート運用

施行: 2026-09-15 以降の新規予想から

## 目的

`ForwardTrial_Ver0.1` の予想判定、2連単1点対象、販売スコアを変更せず、実際に有料・無料へ掲載できるレースだけを公式締切時刻で制御する。

この運用は結果を見て予想条件を変更するものではなく、販売可能性のための時刻ゲートである。

## 基本原則

- 入力は公式出走表CSVの `締切時刻` と販売選別CSVの `販売選別確定日時` を使用する。
- 有料・無料へ掲載できるのは `販売選別確定日時 < 公式締切時刻` のレースだけとする。
- `販売選別確定日時 >= 公式締切時刻` は締切済みとして、有料・無料には掲載しない。
- 締切済みでも、事前予想、2連単1点対象、販売スコアは検証用に変更・削除しない。
- 締切済みの2連単1点対象は `掲載区分=CSVのみ`、`内部販売評価=A-` とし、`選別理由` に公式締切と販売選別確定時刻を記録する。
- 締切前の2連単1点対象だけを従来の販売スコア、2着候補分離度、会場、Rの順で再順位付けし、1〜6位を有料、7〜9位を無料、10位以下をCSVのみとする。
- 締切済みを除いた結果、候補が6Rまたは9R未満の場合は存在する候補だけを掲載し、無理に補充しない。
- 結果参照後にはこのゲートを適用し直さない。`結果参照状態=未参照` の事前段階だけで実行する。

## 実装

正本module:

`boat-racing/src/forward_trial_deadline_gate.py`

標準実行順:

1. `src/forward_trial_predict.py` で事前予想、予想根拠明細、販売選別を同一freezeで生成する。
2. 結果参照前に `src/forward_trial_deadline_gate.py` を公式出走表CSVと販売選別CSVへ適用する。
3. ゲート適用後の販売選別CSVをユーザー向け正本として保存・提示する。
4. 有料・無料の一覧を会話本文へ掲載する場合も、ゲート適用後の販売選別CSVだけを参照する。

例:

```bash
python boat-racing/src/forward_trial_deadline_gate.py \
  --racecard 20260916_公式出走表_....csv \
  --sales 20260916_2連単1点販売選別_....csv \
  --output 20260916_2連単1点販売選別_....csv
```

## ForwardTrial分析との関係

従来どおり、締切後freezeは真正forward集計から分離する。今回の掲載ゲートはそれに加えて、販売時点で締切済みのレースを有料・無料へ表示しないための予防的な運用である。

過去に固定済みの日次販売選別CSVは遡及修正しない。施行日以降の新規予想から適用する。
