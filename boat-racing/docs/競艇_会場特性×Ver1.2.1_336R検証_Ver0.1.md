# 競艇・会場特性 × Ver.1.2.1 前向き336R検証 Ver0.1

## 対象

- Ver.1.2.1前向き検証: 336R（2026/08/13～08/27、8/17結果未取込のため除外）
- 会場特性: `競艇_会場特性マスタ_Ver0.1`（BOAT RACE公式 最近3ヶ月 2026/05/01～07/31）

## 結論

1. 会場の1コース1着率は構造特性として有用だが、単独で会場選別の強い加点・減点にする根拠はまだない。
2. 1号艇Aは会場区分を問わず高い軸成功率で、強イン場だけが有利とは確認できない。
3. 非1号艇Aは全区分で弱く、低イン場でも改善しない。低イン場を理由に非1号艇Aの昇格条件を緩めない。
4. 会場特性マスタと結果ベースのモデル適合度は別資料として管理し、予想入力と結果分析を混ぜない。

## 運用判断

- 会場選別: 会場特性は候補場が拮抗した際のタイブレークに限定する。
- 予想: 会場だけでA判定を作らず、1号艇Aは現行比較を維持。非1号艇Aは低イン場でも緩和しない。
- Ver.1.2.2候補: 非1号艇A昇格条件の厳格化と2着候補選定を優先し、会場特性は補助変数として保持する。
- 結果ベースの会場適合度は会場特性マスタへ混ぜず、別途バージョン管理する。

## 注意

区分別の1号艇Aは各14～33件で95%信頼区間が大きく重なる。したがって、現時点で『強イン場ほど当ロジックの1号艇Aが強い』とは断定しない。
